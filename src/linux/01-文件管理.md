# 文件管理命令

本篇整理千锋 Linux 服务管理课程中的文件管理与编辑命令，涵盖目录创建、文本查看、文件比较、过滤搜索、删除、复制、查找、分割、移动与链接等核心命令。掌握这些命令是 Linux 运维的必备基础。

## mkdir：创建目录

`mkdir` 是 make directory 的缩写，用于创建目录。

```bash
mkdir [选项] 目录名
```

常用选项：

| 选项 | 含义 |
| --- | --- |
| `-m` | 对新建目录设置存取权限 |
| `-p` | 指定路径名称，若路径中某些目录尚不存在则自动创建，一次可建多个嵌套目录 |

**示例**：在 `/home` 下连续创建嵌套目录 user1/user2：

```bash
mkdir -p /home/user1/user2
```

## more：分页查看文件

当文本文件较长、一屏无法显示完毕时使用 `more`。每次显示一屏并在底部提示 `More`，按 `Enter` 显示下一行，按空格键显示下一屏。

```bash
more [选项] 文件名
```

| 选项 | 含义 |
| --- | --- |
| `-d` | 底部提示友好信息（继续/退出/帮助键） |
| `-s` | 多个空行压缩为一个空行 |
| `-p` | 先清屏再显示 |
| `-c` | 每屏显示都清除先前屏幕信息，从顶端显示 |

**示例**：显示 Makefile 内容，每 10 行一屏并清屏：

```bash
more -c -10 Makefile
```

## cat：打印与合并文件

`cat` 将文件内容打印到标准输出，类似于 DOS 的 `type`，同时可用来合并文件。

```bash
cat [选项] 文件名
cat 文件1 文件2 > 文件3
```

| 选项 | 含义 |
| --- | --- |
| `-A` | 将 Tab 显示为 `^I`，并在每行末尾显示 `$` |
| `-b` | 非空行按顺序编号，从 1 开始 |

**示例**：查看 Kconfig 内容，Tab 显示为 `^I` 并对非空行编号：

```bash
cat -Ab Kconfig
```

**示例：合并文件**：

```bash
cat file1.txt file2.txt > file3.txt
```

## diff：比较文件差异

`diff` 以逐行方式比较两个文本文件的异同；比较目录时会比较其中相同文件名的文件，但不含子目录。

```bash
diff [选项] 文件1 文件2
```

| 选项 | 含义 |
| --- | --- |
| `-c` | 显示全部内容并标出不同之处 |
| `-b` | 忽略行尾空格及字符串中连续空格 |
| `-r` | 比较目录时递归比较子目录 |
| `-s` | 两文件相同时显示相同信息 |

**输出格式**：

```
n1 a n3,n4       # 附加（append）
n1,n2 d n3       # 删除（delete）
n1,n2 c n3,n4    # 修改（change）
```

其中 `a`/`d`/`c` 前的行号属于文件 1，后的属于文件 2；以 `<` 打头的行属于文件 1，以 `>` 打头的行属于文件 2。

**示例**：

```bash
diff file1.txt file2.txt
diff -c /home/admin/file3.txt file2.txt
```

## grep：文本过滤

`grep` 按指定字符串逐行搜索文件，找到则输出该行。

```bash
grep [选项] 查找的字符串 文件名
```

| 选项 | 含义 |
| --- | --- |
| `-A NUM` | 同时列出符合条件的行后 NUM 行 |
| `-B NUM` | 同时列出符合条件的行前 NUM 行 |
| `-c` | 只显示符合条件的行数 |
| `-f file` | 从文件读取搜索样式（每行一个） |
| `-i` | 忽略大小写 |
| `-n` | 显示行号 |

**示例**：忽略大小写搜索 rpm 并显示行号：

```bash
grep -ni rpm install.log
```

## rm：删除文件或目录

`rm` 删除目录及其下所有文件与子目录；对链接文件仅断开链接，原文件保持不变。

```bash
rm [选项] 文件或目录
```

| 选项 | 含义 |
| --- | --- |
| `-r` | 递归删除目录及子目录，不加此选项不能删除目录 |
| `-f` | 忽略不存在的文件，不提示 |
| `-i` | 交互式删除，删除前确认 |

> **⚠ 易错点**：`rm -rf` 要慎用。Linux 没有回收站，删除后无法恢复。防止误删可加 `-i` 逐个确认，输入 `y` 才删除。

## touch：创建文件与修改时间

`touch` 改变文件的访问时间和修改时间，若文件不存在则创建。未指定时间则用当前时间。

```bash
touch [选项] 设定的时间 文件
```

| 选项 | 含义 |
| --- | --- |
| `-a` | 修改访问时间为系统当前时间 |
| `-m` | 修改修改时间为系统当前时间 |
| `-c` | 文件不存在时不创建也不提示 |
| `-d` / `-t` | 使用指定日期时间 |
| `-r 参考文件` | 把时间设成和参考文件相同 |

**示例**：

```bash
touch test.txt                    # 创建文件
touch -a test.txt                 # 改访问时间为当前时间
touch -m test.txt                 # 改修改时间为当前时间
touch -a -r linux.txt test.txt    # 用 linux.txt 的时间更新 test.txt
touch -d "20210718 06:40" linux.txt  # 指定具体时间
```

查看时间：`ls -l` 显示修改时间，`ls -lu` 显示访问时间，`date` 显示系统当前时间。

## ln：创建链接

`ln` 在文件或目录间创建链接。默认创建**硬链接**，加 `-s` 创建**软链接（符号链接）**。

```bash
ln [选项] 源文件 目标链接名
```

**硬链接**：通过索引节点（Inode）链接。多个文件可指向同一索引节点。作用是为重要文件建立多个路径名防止误删；只有最后一个链接被删除后，文件数据才真正释放。

**软链接**：类似 Windows 快捷方式，是指向真实文件或目录位置的符号连接。

| 选项 | 含义 |
| --- | --- |
| `-f` | 目标同名文件被删除 |
| `-s` | 建立软链接 |
| `-d` | 允许硬链接目录 |
| `-b` | 对将被覆盖/删除的文件备份 |

**示例**：

```bash
ln /etc/inittab /opt/backup        # 硬链接
ln -b mylinux1.txt mylinux.txt     # 备份后硬链接
ln -s /etc/inittab /opt            # 软链接
```

硬链接的两个文件可看到链接数 `2`（如 `-rw-r--r-- 2 root root ...`）。

## file：显示文件类型

```bash
file [选项] 文件名
```

| 选项 | 含义 |
| --- | --- |
| `-b` | 只显示类型，不显示文件名 |
| `-L` | 显示符号链接指向文件的类型 |
| `-z` | 显示压缩文件信息 |
| `-i` | 非常规文件不再进一步分类 |

**示例**：

```bash
file /etc/init.d/halt   # shell 可执行文件
file /bin/sh            # 符号链接，指向 bash
file /dev/hda           # 块设备文件
```

## cp：复制文件或目录

```bash
cp [选项] 源文件或目录 目标文件或目录
```

| 选项 | 含义 |
| --- | --- |
| `-a` | 保留链接、属性并递归拷贝目录 |
| `-r` | 递归复制目录及其子目录 |
| `-d` | 拷贝时保留链接 |
| `-p` | 保留修改时间和存取权限 |
| `-i` | 目标存在时提示是否覆盖 |

**示例**：

```bash
cp -r ./* /tmp                # 复制当前目录所有内容到 /tmp
cp -r /home/oracle /home/ixdba
```

## find：查找文件

```bash
find 路径 [-options] [-print -exec -ok 命令 {} \;]
```

**options 常用格式**：

| 格式 | 含义 |
| --- | --- |
| `-name '字串'` | 按文件名匹配（支持 `*` `?` `[]`） |
| `-lname '字串'` | 匹配符号链接文件 |
| `-gid n` / `-uid n` | 按属组/属主 ID 查找 |
| `-empty` | 查找大小 0 的文件 |
| `-group '字串'` / `-user '字串'` | 按组名/用户名查找 |
| `-size n` | 按大小查找，加 `c` 表示字节 |
| `-mtime +n` / `-n` | 按修改时间：`+n` n 天前，`-n` 今天到 n 天前之间 |
| `-type 类型` | 按类型：b 块设备、c 字符设备、f 普通文件、l 符号链接、d 目录、p 管道、s socket |
| `-prune 目录` | 搜索时跳过指定目录 |
| `-depth` | 先当前目录后子目录 |

- `-print`：输出结果到标准输出。
- `-exec`：对搜索到的文件执行命令，`{}` 代表搜索到的文件，命令必须以 `\;` 结尾。
- `-ok`：同 `-exec` 但会询问是否执行。

> **⚠ 易错点**：`-exec 命令 {} \;` 中 `}` 与 `\` 之间必须空格；`\( -path ... \)` 中括号与 `-path`、路径与 `\` 之间都要空格。

**示例**：

```bash
# 在根目录查找 ixdba 用户、普通文件、2天前、跳过 /usr/bin 的 main.c
find / -path "/usr/bin" -prune -o -name "main.c" -user ixdba -type f -mtime +2 -print

# 删除以上结果
find / -path "/usr/bin" -prune -o -name "main.c" -user ixdba -type f -mtime +2 -print -exec rm {} \;

# 查找所有 0 字节普通文件并列出详情
find / -type f -size 0 -exec ls -al {} \;

# 删除 /var/log 中 7 天前的普通文件（交互确认）
find /var/log -type f -mtime +7 -ok rm {} \;
```

## split：分割文件

```bash
split [选项] [input_file] [output_file]
```

| 选项 | 含义 |
| --- | --- |
| `-b size` | 按大小分割，单位 b=512B、k=1KB、m=1MB |
| `-n` | 指定每个文件行数，缺省 1000 行 |
| `-d` | 文件序列以数字形式命名 |
| `-a` | 序列长度，默认 2 |

未指定输出名默认以 `x` 开头（xaa、xab…）。

**示例**：

```bash
split -b 10M access_log access_log_bak      # 每个 10MB
split -b 2M -d -a 3 /opt/etc.zip /opt/etc.zip_bak  # 生成 etc.zip_bak001、002、003
```

## mv：移动或改名

- 源、目标都是文件/目录：重命名。
- 源是文件、目标是目录：移动文件。
- 源是目录：目标只能是目录，完成目录重命名。

```bash
mv [选项] 源文件或目录 目标文件或目录
```

| 选项 | 含义 |
| --- | --- |
| `-i` | 交互式，覆盖前询问 |
| `-f` | 禁止交互，默认覆盖 |

**示例**：

```bash
mkdir myDocument && touch Document
mv Document myDocument       # 移动
mv myDocument myDocument_1   # 改名
```

## 小结

| 命令 | 作用 | 高频参数 |
| --- | --- | --- |
| mkdir | 创建目录 | `-p` 递归创建 |
| more / cat | 查看内容 | cat `-b` `-A` |
| diff | 比较文件 | `-c` 全文标记 |
| grep | 文本过滤 | `-i` `-n` `-A` `-B` |
| rm | 删除 | `-rf` 慎用 |
| touch | 创建/改时间 | `-a` `-m` `-d` |
| ln | 链接 | `-s` 软链接 |
| file | 文件类型 | `-b` |
| cp | 复制 | `-r` `-a` `-p` |
| find | 查找 | `-name` `-mtime` `-type` `-exec` |
| split | 分割 | `-b` `-d` |
| mv | 移动/改名 | `-i` `-f` |

> 核心命令速记：`mkdir -p`、`grep -ni`、`rm -rf` 慎用、`cp -rp`、`find -exec {} \;`。
