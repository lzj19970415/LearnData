# MySQL软考学习总览（数据库系统工程师一次考过完整攻略）

> 这套笔记是写给**数据库零基础、白天上班晚上复习**的在职考生看的软考中级《数据库系统工程师》通关手册——每篇都按"先讲人话、再上定义、再上表格"的师兄带学模式来写，目标是**背会就能一次通过**。

⚠️【必考】四大件里，**①③ 两件几乎年年必考**，且互相咬合：ER 图转出来的关系模式，往往就是让你继续求候选键、判断范式的原材料。所以 02、03、05 三篇是全套笔记的"心脏"，无论多忙都要优先保证。

### 四大件逐件展开：问法 / 评分点 / 丢分点

**① ER图与关系模式设计**

| 维度 | 内容 |
| --- | --- |
| 常见问法 | 补全缺失的实体/联系/属性；判断联系类型；转换为关系模式并指出主键外键 |
| 评分点 | 联系类型判断正确、两端标注 1/n/m、转换规则套对、主键下划线/外键标注齐全 |
| 经典丢分 | m:n 不拆独立表；把联系属性错挂到实体上；漏标外键 |

**② SQL 建表与查询**

| 维度 | 内容 |
| --- | --- |
| 常见问法 | 写含主键/外键/非空/检查约束的建表语句；补全 SELECT；建视图；建索引；授权语句 |
| 评分点 | 关键字拼写、约束定义完整、JOIN 条件正确、GROUP BY 与聚合配套 |
| 经典丢分 | 手写顺打字错（括号引号）；忘写约束；SELECT 里混入非法字段 |

**③ 规范化（候选键 / 范式）**

| 维度 | 内容 |
| --- | --- |
| 常见问法 | 求候选键；判断范式等级并说明理由；指出插入/删除/冗余异常；分解到 3NF |
| 评分点 | 四步法过程完整、闭包展开写出来、异常点举例具体、分解后主外键交代清楚 |
| 经典丢分 | 只给答案不写过程；候选键漏答第二个；把 2NF 问题当成 3NF 的判定依据 |

**④ 事务与并发控制**

| 维度 | 内容 |
| --- | --- |
| 常见问法 | 判断调度结果是否正确；说明应采用的封锁协议；死锁成因与预防；两段锁协议 |
| 评分点 | 指出冲突操作对、可串行化判断依据、S/X 锁相容矩阵、协议名称准确 |
| 经典丢分 | 只说结论不给依据；混淆两段锁协议与三级封锁协议；丢失修改和不可重复读不分 |

## 六、学习方法三条（师兄血泪经验）

1. **表格化记忆，别背段落。** 这套笔记把所有能对比的内容都做成了表格，因为选择题考的就是"区分度"——DB 和 DBMS、逻辑独立和物理独立、1NF 和 2NF 的区别，一张表就能锁死。复习时直接背表格列差异，别整段朗读。
2. **先保证上午 45+，再打磨下午。** 上午题量大、覆盖广，但 6 成集中在数据库本身；把 01~08 篇的"必考点"吃透，上午就有底了。下午案例题套路固定（09 篇会拆解评分点），属于"会一个模板就能拿一片分"的题型，越到后期投入产出比越高。
3. **用"输出"检验"输入"，别自我感动。** 看懂了 ≠ 会写。每篇末的自测题必须**合上笔记做**；案例四大件必须**动手在纸上/记事本里写完整答案**再对参考。错题当天记入错题本，第二周只刷错题本。

## 七、新手常见问题 Q&A

**Q1：我是纯零基础，MySQL 命令都没敲过，来得及吗？**

来得及，而且比你想的容易。软考中级考的是**数据库原理**，不是运维实操——MySQL 命令在考试里的深度只到"建表、查询、索引、引擎"这个层面，08 篇一篇就能覆盖。你不需要装数据库环境也能备考，但强烈建议装一个（哪怕用网页版在线 SQL 练习），把 04 篇的语句亲手跑一遍，肌肉记忆比背诵牢固十倍。

**Q2：上午 75 道题范围特别广，硬件、操作系统、网络都要考，我其他课目没学过怎么办？**

战略放弃 + 精准补课。它们合计只占约 2 成（15 分左右），而且考得浅——都是"名词认脸"级别的题。你不需要系统学《操作系统》，只需要把本库对应的"速记卡"级知识点过两遍，能认出正确选项即可。把省下来的时间全部砸回数据库 6 成的主战场。

**Q3：机考和笔试有什么区别？需要注意什么？**

题还是那些题，但操作习惯不同：① 答题在电脑上点选/输入，建议平时就在电脑上做电子题库适应屏幕读题；② **机考通常科目连考**，中途体力消耗大，考前一周务必按真实节奏做整套限时模拟（连着做完上午+下午）；③ 平时练案例题就直接在记事本里打字写 SQL，别只写纸上——手写很顺的语句，打字时括号引号都可能出错。

**Q4：这次没过怎么办？心态崩了。**

先看崩在哪一科。软考不能单科保留，但你的复习成果是可复用的：过了的那科说明对应模块你已经掌握，下次只需要重点补短板模块。这套笔记按模块组织，就是为了让二战的人可以"哪里薄弱点哪里"，而不是从头再来一遍。当然，我们的目标只有一个：**这一次，两科一起过。**

## 八、机考考场策略（细节决定及格线）

| 阶段 | 要点 |
| --- | --- |
| 考前一周 | 全真限时模拟 2~3 套（上午+下午连着做），练连续作战的体力和专注力 |
| 考前一晚 | 只看速记卡和错题本，**不学新内容**——新知识临考记不住，只会放大焦虑 |
| 上午科目 | 快慢分离：一眼会的先做，计算题控制单题时间，交卷前统一检查有无未答题（机考系统内未作答的题通常有明显标记，交卷前务必清一遍） |
| 下午科目 | **先看问题再读题干**，带着问题找材料；按评分点分条作答（①②③），一条一个关键动作 |
| SQL 作答 | 关键字用大写、语句写完整；写不出完整语句也要写出关键骨架（如 GROUP BY、HAVING），评分点按关键词给分 |
| 时间不够时 | 宁可每问都写要点，不要一道题写到完美、另一道交白卷——下午是按点给分 |
