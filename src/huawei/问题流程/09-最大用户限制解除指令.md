VPN 登录提示"达到最大用户限制"（在线会话数占满）时，查看并踢掉占用会话的账号，解除限制。

## 步骤

### 1、查看当前登录 VPN 的在线用户

```
dis sslvpn session
```

- 从输出里看哪些账号还在线、占了会话

### 2、踢掉占用会话的用户（强制注销下线）

```
sslvpn context ssl
force-logout user yzw_szgs_wxj_appcs
```

- 把 `yzw_szgs_wxj_appcs` 换成要踢的账号名（上一步在线列表里看到的那个）

### 3、验证

```
dis sslvpn session
```

- 确认该账号已下线；被踢用户重新登录 VPN 即可正常使用

## 注意

- 适用场景：账号多处登录 / 会话未正常退出占用名额，导致新用户登录报"超过最大用户数"
- force-logout 只注销该账号的当前会话，不影响账号本身和已下发的权限配置
