## 1、服务器遭受攻击后应对策略

- **处理方案**
  - 登录（M9000 防火墙）https://10.240.3.1/wnm/frame/index.php#M_Dashboard ，点击对象、点击 ACL 规则组，然后输入 3002 规则组，把要封堵的 IP 添加进来，3002 添加完成后输入 3003 也进行同样的操作，3002 需要截图，3003 不需要。

## 攻防演练 IP 解封

- 需要登录封堵 1、2 路由器（10.245.49.14、10.245.49.15）以及园区接入防火墙 M9000（10.240.0.2），防火墙要进入 3002、3003 规则解封。

## 正常 IP 解封

- 信创外、非信创外网 2：59.50.3.0、59.50.39.0 这两个 IP，则需要解封 M9000 的就行，M9000 是 3002、3003 规则

## 操作步骤

- 两台路由器：dis cu 全局查看，输入要解封的 IP，例如 192.168.2.1 进行查找
- 查找出来在这条路由中：ip route-static 192.168.2.1 255.255.255.255
- 执行：undo ip route-static 192.168.2.1 255.255.255.255
- M9000 防火墙可以在 web 界面进行操作
