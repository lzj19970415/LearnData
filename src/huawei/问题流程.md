# 问题操作

## 添加策略流程

### 举例
- **源IP**：10.100.7.228（内网云）
- **目的IP**：10.160.35.0/24（外网云）
- **目的端口**：19114

### 流程
- 源端：登录内网云-云资源池（非信创内网云采用扁平网络部署，不需要写防火墙以及路由表），因为是源端访问出去的安全组默认放通整个段，不需要再写安全组了，由于硬件防火墙出去的策略全部放通也不需要写，核心交换机的路由之前已经写入。
- **目的**
  - 安全组
1、登录信创外网云-云资源池-进行IP搜索出来后进入主机选择点击安全组（因为是目的端，这里写安全组是为了把源端的IP放进来），搜索用本平台IP搜索，查看入方向原有的规则是否已经存在，如果不存在则添加，因为要把源端的IP添加进入方向才能访问目的端，所以这里添加的是源端IP。
  - 防火墙
2、资源中心-网路服务-防火墙-规则集（规则集里面没有的就说明原来因为某些原因所以没有放通，那就默认都是通的不再需要添加，这里要搜索规则是用本平台的IP进行搜索，这里是在目的端，所以搜索的IP也是输入的目的端IP），进入防火墙规则组后输入源端IP（10.100.7.228）搜索是否存在（为什么输入源端IP，现在所在的是目的端平台，那么这里的源IP相对这个平台来说就是目的IP），存在不用管，不存在要添加规则（查看优先级序号再写），目的端是10.160.35.0/24，但是现在所处的就是目的端平台，所以10.160.35.0/24这个IP就是源IP，源IP相对目的端的防火墙来说就是目的端IP（10.100.7.228）。写完要点击启用-确定-同步配置。
  - 路由表
3、登录信创外网云-网络服务-路由表（从路由表中看名称看不出来当前网段或者IP是属于哪个路由组的可以从网络资源-VPC网络中查看），进入路由组里点击VPC路由器，这里是查找规则组，所以要输入本平台的IP，确定存在当前要加的网段后-路由条目-搜索用目的端IP（这里是在目的端平台，所以相对来说源IP才是目的IP（10.100.7.228）），查找没有后需要自行添加（下一跳根据之前写的加入，目的地址（当前所在目的端平台，相对来说源端IP才是目的地址10.100.7.228））。
硬件防火墙（信创外防火墙），进入用户视图-安全策略组security-policy IP-查看当前配置（dis th），查找（输入目的IP），然后选择一个规则组（尽量选择少的添加），查看是否都包含源端和目的端和端口，如果不包含需要添加，

## 聚合问题

### 物理机网卡断联排查：
1、Ip -4 a查看对应bond有无UP
2、ip -s link show br_bond0 查看bond丢包情况
3、cat /proc/net/bonding/bond0 查看对应物理网卡
4、dmesg | grep -i "link.*down" 查看最近断联情况
5、ethtool  -p  enp61s0f0  计算节点服务器网卡电灯定位问题命令
通过网卡标签找到对端交换机口看聚合和网线口是否正常

## 系统加固镜像问题处理

使用系统加固镜像时出现问题的处理方法：

1. 先查看 sshd 服务是否起来
2. 重启失败就修改 key 问题：0640 权限过开放，修改到 600，命令：`chmod 600 /etc/ssh/ssh_host_ed25519_key`
3. 密码登录也被限制，需修改：`vi /etc/ssh/sshd_config`，将 `PasswordAuthentication no` 修改为 `PasswordAuthentication yes`，然后重启：`systemctl restart sshd`
4. 如果不通外网，可能 DNS-IP 不对。先测试 ping `110.242.74.102`，通的话说明不需要在 M9000 上开策略（如果不通，以 139 网段为例，需加 ACL 策略：`rule 308 permit ip source 10.130.139.0 0.0.0.255`）。修改 DNS 地址可改为 `223.5.5.5`。
