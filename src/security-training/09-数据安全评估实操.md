# 09 数据安全评估实操（模拟演练）

> 对应 10月21日下午（培训标注"重点"）：基于模拟企业的评估材料，按评估指标完成风险研判，形成评估结论、评估依据与截图证明。参考数据安全技能竞赛"数据场景仿真"赛制。

## 一、评估输入材料清单（发什么看什么）【背】

| 材料 | 看什么 |
| --- | --- |
| ① 数据分类分级台账 | 分级是否正确、覆盖是否全（有没有漏的数据集） |
| ② 数据安全管理制度 | 有没有制度、制度与台账是否对得上 |
| ③ 权限分配表 | 谁能访问什么级别的数据，是否最小权限 |
| ④ 平台权限配置策略 | 配置与制度是否一致（制度说最小化、配置里却是全员可读=问题） |
| ⑤ 日志记录 | 有没有操作留痕、有没有审批记录 |

**五大件口诀：台账、制度、权限表、配置、日志审批。**

## 二、评估方法：三层核验法【背，核心方法】

```
第一层【有没有】：制度/台账/日志 是否存在（缺项=管理缺失）
第二层【对不对】：内容是否合规（分级错误、权限超出）
第三层【落没落地】：制度说一套、配置是另一套（两张皮=最大扣分点）
```

## 三、风险研判操作步骤【背】

```
① 逐条读台账：抽查高敏感数据集（用户身份、位置、通信记录）
② 对照分级规则（GB/T 43697 / 行标）：判分级是否定低了
③ 权限交叉核对：权限表 × 配置策略，找"越权访问""共享账号""离职未回收"
④ 日志核对：敏感数据访问有没有记录、超权限访问有没有告警
⑤ 审批链核对：批量导出/出境有没有审批记录
⑥ 形成问题清单 → 逐项定风险等级（高/中/低）→ 给整改建议
```

## 四、评估结论写法（三要素）【背，必考】

每个问题项都要按三要素写：

```
【结论】xxx 数据集分级错误 / 存在越权访问风险（一句话定性）
【依据】对照《数据安全法》第X条 / GB/T 43697-2024 第X条 / 《xx管理制度》第X条 + 材料中的具体证据（台账第X行、配置截图）
【证明】截图编号+材料位置（台账页码、配置项名称、日志时间戳）
```

例：
- 结论：用户位置数据（台账编号 D-017）定级为"一般"，低于应有级别。
- 依据：GB/T 43697-2024：位置信息泄露危害较高，应定"重要"；台账 D-017 行。
- 证明：截图 03（台账 D-017 行）。

## 六、评分与失分点【背】

1. **截图必须带上下文**：光截个表不算证明，要能看到"这是台账、这是第几行"。
2. 依据不能只写"违反相关规定"——**必须写到具体法条/标准条目**。
3. 每项风险都要给**整改建议**（缺建议丢一半分）。
4. 时间分配：五大件先**全部粗读一遍**（10分钟），再逐项深挖，别一头扎进台账。

## 七、高频考点提示

1. 五大件材料名必背（台账、制度、权限表、配置、日志审批）。
2. 三层核验法：**有没有→对不对→落没落地**。
3. 三要素答题：**结论+依据+证明**，写不齐三件套就丢分。
4. 模式库至少背 6 条，考场对号入座最快。
5. 整改建议必写，格式"**措施+责任角色+验证方法**"。
