# 09 数据安全评估实操（拿到一堆材料，怎么"审"）

> 承接 04。你已经懂数据要分级。这一章讲**"评估"到底怎么操作**：给你一堆材料，你怎么把它们审一遍、找出风险、下结论。这是数据安全里最实操的一环。

## 一、先说人话：评估是什么

**评估 = 拿着"证据材料"去审查一家单位的数据安全做得到不到位。**

把它想成**审计**：单位声称"我很安全"，你**不信嘴说，只信纸面证据**——制度、台账、权限表、日志、审批记录，逐样翻，找出"说得好看但实际没做到"的地方。

> 一句话：**评估 = 翻材料、找漏洞、下结论。** 材料=证据，不能空口无凭。

## 二、先认材料：评估要看"五大件"

拿到评估任务，先分清"该看哪些材料"（这五大件是核心）：

| 材料 | 你要审什么 |
| --- | --- |
| ① 数据分类分级台账 | 数据有没有都登记、级别定得对不对 |
| ② 数据安全制度 | 有没有明文规定（没制度=大问题） |
| ③ 权限分配表 | 谁有权限访问什么级别，是否**最小权限** |
| ④ 平台权限配置 | 实际配置跟制度写的是不是**一致** |
| ⑤ 日志 + 审批记录 | 访问敏感数据有没有留痕、批量导出有没有审批 |

**人话记这五样**：**台账、制度、权限表、配置、日志审批**。

## 三、评估的核心方法：三层核验（最有用的一招）

别急着找毛病，按三层逻辑走，稳且全：

```
第1层【有没有】  制度/台账/日志 存不存在 → 缺了=管理缺失
第2层【对不对】  内容定级对不对、权限给得对不对
第3层【落没落地】制度说一套、实际配置/日志是另一套 → 两张皮=最大问题
```

**举例子**（你就懂了）：

- 制度写了"用户数据只允许管理员看"——这是第1层（有制度，过了）。
- 看权限表：普通员工竟然能看用户位置数据——第2层（权限给错了，问题）。
- 制度明明写"批量导出要审批"，但日志里一堆批量导出、没有审批记录 → 第3层（**制度没落地**，这是最要命的问题）。

**人话**：**最值钱的问题是"两张皮"——口头一套、实际一套。** 评估最常考的就是抓这个。

## 四、评估步骤（跟着走）

```
① 把五大件快速扫一遍（先有全局印象，10分钟）
② 逐条看台账，重点抽查高敏数据（位置/通信记录等）
③ 权限交叉核对：权限表 × 配置，找"越权""共享账号""离职没回收"
④ 日志核对：敏感数据访问有没有留痕、异常访问有没有告警
⑤ 审批链核对：批量导出/出境有没有走审批
⑥ 汇总成"问题清单"，逐项定风险等级（高/中/低）
```

## 五、怎么下结论（写评估意见的标准格式）

每个问题项，**三件事写全**才叫完整结论：

```
【结论】一句话定性：XX 数据定级过低 / 存在越权访问
【依据】引具体的：法条（数据安全法第X条）/ 国标（GB/T 43697）/ 单位制度（第X条）+ 材料证据
【证明】截图/材料位置（台账第X行、配置项、日志时间戳）
```

**例**：
- 结论：用户位置数据定级为"一般"，低于应有级别。
- 依据：GB/T 43697-2024 位置信息泄露影响较高应定"重要"；见台账 D-017 行。
- 证明：截图 03（台账 D-017 行）。

> 三件事缺一不可：**只给结论没依据=没根据；给了依据没截图证明=没实据。**

## 六、常见问题速查表（对号入座）

| 你发现 | 怎么定性 |
| --- | --- |
| 台账缺数据集 | 分级覆盖不全 |
| 高敏数据定级过低 | 分级错误 |
| 员工可看核心数据 | 未最小权限 |
| 制度与配置不符 | 制度未落地（两张皮） |
| 无访问日志/日志不全 | 技术措施缺失 |
| 批量导出无审批 | 流程缺失 |
| 离职账户权限还在 | 权限管理缺陷 |
| 数据出境未评估 | 出境合规缺失 |

## 小结（人话速记）

1. 评估 = **打材料、看有没有做对、下结论**，不信嘴说信证据。
2. 五大件：**台账、制度、权限表、配置、日志审批**。
3. 三层核验：**有没有 → 对不对 → 踩没落地**（"两张皮"最伤）。
4. 结论三要素：**结论 + 依据 + 证明**。
5. 常见问题对号入座（越权/定级错/两张皮/无日志）。

> 动手建议：拿单位一份真实材料（台账/权限表/日志），按"三层核验"挑 3 个问题，练着写"结论+依据+证明"——会写这个，你就是能上手的数据安全评估了。
