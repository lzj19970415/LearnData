## 二、Web 日志攻击链还原五步法【背】

```
① 按时间排序，圈定事件窗口
② 按攻击者 IP 聚类（他的所有请求）
③ 找首次入侵点（第一个成功 payload，状态码 200）
④ 串联后续动作（落地文件→连接 webshell→执行命令）
⑤ 输出时间线报告：时间+动作+证据行
```

实操要点：
- `awk '{print $1}' access.log | sort | uniq -c | sort -rn | head`（高频 IP，找扫描者）
- `grep "union" access.log`（注入证据）
- 用 Excel/脚本给"IP-时间-URL-状态码"做透视，时间线一目了然。

## 四、钓鱼邮件溯源【背】

### 邮件头三看

```
① Received 链：从下往上读，逐跳还原投递路径（真发件服务器在最后一跳）
② Return-Path / MAIL FROM：真实回信地址（与显示名对比，伪造即露馅）
③ X-Originating-IP：原始发送 IP
```

### 常见伪造手法与识别

- 显示名伪造（From 显示"IT管理员"，地址实为陌生邮箱）→ 看完整地址不看昵称
- 相似域伪造：`tec1.com` vs `tec.com`、punycode 同形域 → 逐字符核对域名
- SPF/DKIM/DMARC 三个验证结果看邮件头：`spf=fail` 即高度可疑

### 邮件取证动作

- 隔离邮件（从全员邮箱撤回/提醒）
- 提取附件 hash（MD5）入库比对、放沙箱引爆，别双击
- 链接类：用安全环境访问，跟踪 302 跳转链到真实落地页

## 五、反制思路与合规边界【背，必考！】

### 可以做

1. 加固自身：封禁 IP、WAF 规则、蜜罐诱捕（在**自己授权资产**上）
2. 收集证据：全流量留存、日志保全、报警（公安网安/上级监管）
3. 反溯源：蜜罐里放假数据观察攻击者行为、记录指纹

### 不能做【背，红线】

1. **不得对攻击者 IP 主动发起攻击**（反打回去 = 违法，可能打到肉鸡/无辜者）
2. 不得未授权扫描第三方系统（"查他到底是谁"也不行）
3. 反制手段仅限**自己拥有和被授权**的资产范围
4. 证据链要合规：原始日志、哈希校验、时间戳，保证司法可用

一句话总结：**反制=以守为攻（蜜罐+诱捕+取证），不是打回去；越界反制，受害者变违法者。**

## 六、高频考点提示

1. Kill Chain 七步顺序必背；答题时"给出环节+对应日志证据"两列全。
2. 还原五步法：**时间→IP→入侵点→串联→时间线**。

4. 合规红线一句话背下来：**不主动打回去、只在自己资产上反制、证据要司法可用**。
