# 06 溯源反制入门（顺着痕迹揪出"谁干的"）

> 前面你学会了查日志。这一章讲：**把这些痕迹串起来，还原攻击者是怎么一步步进来的（溯源），以及我们能做到哪一步、绝不能越界（反制）。**

## 一、先说人话：什么是溯源、什么是反制

- **溯源** = 破案。从日志、留下的痕迹里，把"谁（IP）、什么时候、从哪进来、干了什么、怎么离开"串成一条**时间线**。
- **反制** = 处理。但重点**不是"打回去"**，而是：**留证据、堵漏洞、必要时报警**，并且**在自己的地盘上设陷阱诱捕**。

> ⚠️ 记住这条红线：**反制 = 以守为攻，不是以牙还牙。**主动攻击攻击者的 IP，很可能打到无辜的人（肉鸡），而且你自己就违法了。

## 二、攻击是怎么一步步发生的（攻击链，人话版）

一次攻击，通常是"一步一步"来的，有个标准套路（叫 Kill Chain），记成七步：

```
①踩点侦察 → ②准备武器 → ③送进来 → ④打进去(利用) → ⑤装后门 → ⑥连上控制 → ⑦搞破坏/拖数据
```

- 侦察：先扫你的网站有哪些漏洞（日志里一堆 404）
- 利用：找到漏洞打进去（日志里出现 payload）
- 装后门：往服务器塞个 webshell / 新账户（之前学的持久化）
- 控制：连回来干坏事（服务器出现陌生外联）

**溯源就是把"上面每步"对应的日志证据找出来，串成线。**

## 三、还原攻击过程（五步实操）

```
① 按时间圈范围：攻击是"突然集中爆发"的，先定位时间段
② 按 IP 聚：找出那个"主要攻击者 IP"，把它所有请求拉出来
③ 找第一个成功：第一次返回 200 的恶意请求=首次打入点
④ 往后串：看打入后他干了什么（落地文件、连 webshell、执行命令）
⑤ 输出时间线：时间 + 动作 + 证据行 三列，一条条写清
```

**人话**：就像看录像回放，把"他先干这、后干那"按时间排出来，证据就清晰了。

## 四、攻击者画像（他大概是什么人）

不用查户口，看四个维度就能大致判断：

```
① 从哪来：IP 归属（机房 / 家庭宽带 / 境外）
② 用什么工具：UA / 工具指纹（sqlmap 自动化 / 手工）
③ 什么习惯：作案时间（推时区）、命名风格
④ 想干嘛：拖数据？勒索？挖矿？横向？（看它最后干什么）
```

> 小技巧：把他的请求时间画成图，找出"他固定睡觉的 8 小时"，就能反推他大概在哪个时区。

## 五、钓鱼邮件怎么溯源

- 钓鱼邮件 = 伪装成正经人发你链接/附件，骗你点。
- 溯源看**邮件头**（邮件里有隐藏的"投递记录"）：

```
① Received 链：从下往上读，还原投递路径（真发件服务器在最后）
② Return-Path：真实回信地址（跟"显示名"对不上=伪造）
③ X-Originating-IP：原始发件 IP
```

- **防伪核对**：SPF / DKIM / DMARC 三个验证，邮件头里有 fail 的＝高度可疑。
- 附件别双击，先**取 hash 丢进沙箱**看行为；链接用安全环境点，看 302 跳到哪。

## 六、合规边界（必须背，这条不能错）

**你可以做（对自己、对自己授权的资产）：**

- 封禁攻击 IP、上 WAF 规则、开蜜罐**诱捕**（蜜罐=假装的有价值系统，专门钓攻击者、套他指纹）
- 全流量留存、日志保全、报警上报（公安/监管）

**绝不能做（做了你就违法了）：**

- ❌ 对攻击者 IP **主动发起攻击**（"反打回去"是大忌，可能打到肉鸡、无辜者）
- ❌ **未经授权扫描**第三方系统（想查他是谁？那也不行）
- ❌ 反制超出**你自己授权**的资产范围

> 一句话：**反制 = 守株待兔（蜜罐诱捕）+ 留证上报，不是反击回去。越界反制，受害者会变成违法者。**

## 小结（人话速记）

1. 溯源=串证据成时间线；反制=堵漏+留证+诱捕，**不打回去**。
2. 攻击七步链：侦察→武器→投递→利用→后门→控制→行动。
3. 还原五步：**圈时间→聚IP→找首次成功→查落地→写时间线**。
4. 邮件看：Received（从下往上）、Return-Path、X-Originating-IP。
5. 红线：**不主动攻击、只在自己资产上反制、证据要合法可用**。

> 动手建议：拿一份真实的 access.log，按"五步"把某个 IP 的攻击过程还原成时间线——会了这个，溯源就是你的本事了。
