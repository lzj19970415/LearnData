# 安全入门实战教程（网络安全 · 数据安全 · AI安全）

> 一套从零开始、能看懂、能上手的安全入门教程。**与软考中级无关，独立一套。**

## 这套教程是给谁看的

给**安全小白**写的。你可以不懂安全、没做过攻防，但如果有 IT / 运维 / 网络的底子（比如会敲命令、懂点服务器），上手会更快。

学完的目标：**能看懂常见安全问题是怎么发生的、能在自己搭的练习环境里动手跑一遍、遇到常见的攻击能识别和应对**——而不是只会背几个术语。

## 怎么学（每条都按三步来）

```
① 先讲人话：这是什么、为什么会发生（用类比，不堆黑话）
② 再上手实操：搭练习环境、跑命令、看结果
③ 最后留一个小速记块：只留必须记住的几点
```

## 新手常见问题

- **要不要先买本书/报课？** 不用，把这篇按顺序看完、动手跑一遍，比看十本书强。
- **要不要配靶机？** 建议搭一个练习环境（章节里会给方法）。安全学习必须动手，光看记不住。
- **会不会太难？** 每篇都从人话讲起，跟得上。卡住就重看那节的"人话"部分，别硬啃。
- **学完能直接上岗吗？** 能帮你把基础打实、有得聊、会动手。真正的"上岗"还需要积累实战（多看真实案例、多动手练），这套是你能往上走的地基。
