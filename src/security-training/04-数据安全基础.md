# 04 数据安全入门（数据怎么分级、为什么有这些法律）

> 这一块和你电信工作最相关。目标不是背法律条文，而是**懂一个事：你的数据到底多重要、值不值得保护、该不该管。**

## 一、先说人话：为什么数据要"分级"

把公司的数据想成你家里的东西：

- **一般东西**（毛巾、纸巾）→ 丢了也没什么，随便放。
- **重要东西**（身份证、银行卡、存款）→ 丢了很麻烦，要锁起来、存单要收好。
- **核心东西**（房产证、保险柜密码）→ 丢了可能倾家荡产，必须最高级别保管，而且越少人知道越好。

**数据一模一样**。不同数据"要是泄露了影响多大"完全不一样，所以要用**不同的保护力度**。这就是"**分类分级**"——先分门别类，再按重要程度定级，再按级别保护。

> 一句话：**分级 = 按"泄露了后果多大"把数据分成几个保护等级，贵的锁得更紧。**

## 二、数据怎么分级（记这三个等级）

国标里分三级（记）：

| 等级 | 泄露后果 | 例子（贴近你电信业务） |
| --- | --- | --- |
| **一般数据** | 影响不大 | 公开信息、普通内部资料 |
| **重要数据** | 危害国家安全/公共利益/企业重大利益 | 大量用户信息、位置、通信记录、网络设备信息 |
| **核心数据** | 可能严重危害国家安全 | 极少，涉及国计民生的关键数据 |

**判等级看"三性"**（很好记，就三个字）：保密性（漏出去）、完整性（被人改了）、可用性（被人弄坏了）。只要影响到这几样，级别就往高走。

## 三、为什么要立法（人话讲法律）

- **《数据安全法》**（2021.9.1 施行）：给数据安全立了个总规矩，**确立了分级保护制度**，规定重要数据怎么管、出境怎么审批。
- **《个人信息保护法》**（2021.11.1 施行）：专门管**"个人"的信息**（手机号、身份证、住址、位置…），要求"单独同意""最小化收集"。

**这两个法记住两句就行：**
- 数据法管"**数据**"（重点保护重要/核心数据）
- 个保法管"**个人信息**"（重点保护每个公民的隐私）

> 在电信企业，用户手机号、位置、通信内容是最敏感的一类，基本是最该保护的"重要数据"档。

## 四、做数据安全要抓什么（运维视角）

面对一套评估/治理，就盯这几件：

```
① 台账：把所有数据列清楚、定好级（这是起点）
② 权限：谁能访问哪个级别，是不是最小权限（谁"太能看"了？）
③ 日志：访问敏感数据有没有留痕、能不能追
④ 制度：公司有没有明文规定（没制度=管理缺位）
⑤ 处置：泄露/出问题有没有应急和上报机制
```

**人话**：老板问你"数据安全做到没"，你就拿这五样核对一遍——**有没有登记、有没有定级、谁在看、看不看留痕、出事了怎么办**。

## 五、数据安全评估是什么（一个实操切入点）

"评估"就是**按一套标准把上面五样检查一遍**，找出风险并下结论。具体怎么做，看 [09 数据安全评估实操](09-数据安全评估实操.md)。这里你先知道它是干嘛的就行。

## 小结（人话速记）

1. 分级 = **按"泄露后果严重程度"分档，贵的锁更紧**。
2. 三档：**一般 / 重要 / 核心**；核心最高。
3. 判据看**三性**：保密、完整、可用。
4. 两个法：**数安法（管数据）+ 个保法（管个人隐私）**。
5. 落地五件事：**台账 / 权限 / 日志 / 制度 / 应急**。
