# 08 全链条综合实验（比赛题型带练）

> 对应 10月20日下午：模拟业务系统靶机完成"漏洞利用→修复→加固→应急排查→溯源反制"全链条题目。

## 一、全链条五段式【背，本篇核心】

```
①漏洞利用 → ②修复 → ③加固 → ④应急排查 → ⑤溯源反制
```

每段都有独立得分点，**比赛按段给分，做完一段交一段**，别卡死在一段。

## 二、分段时间分配（建议）【背】

假设单题 60 分钟：

```
漏洞利用 15min → 修复 10min → 加固 15min → 应急排查 10min → 溯源反制 10min
```

- 原则一：**先易后难**，一段卡住 10 分钟先跳过做下一段。
- 原则二：**每完成一段立刻截图存证**（payload、命令、结果三合一）。

## 三、各段得分要点清单【背】

### ① 漏洞利用

- 找到漏洞位置（写清：**哪个功能/哪个参数**）
- 利用成功证据：回显截图（数据/命令执行结果）
- 手工 payload 优先，写进报告完整粘贴

### ② 修复

- 改什么：**参数化查询 / 上传白名单+重命名 / 组件升级**（对症下药）
- 怎么证：用原 payload 复测，失败截图

### ③ 加固

- 按三基线答（系统/中间件/数据库），每条要有**具体配置项或命令**
- 例：`Options -Indexes`、`deny all`、root 禁远程——能写命令就别空说

### ④ 应急排查

- 四步：进程→持久化→账户→日志（背 01 篇）
- 输出：可疑项清单+处置动作（删后门/停服务）

### ⑤ 溯源反制

- 时间线：IP+时间+动作三列
- 合规收尾：封禁、上报、留证；**绝不能写"反打回去"**（写了扣大分）

## 四、答题报告模板（比赛直接套）【背】

```
【结论】一句话：系统存在 XX 漏洞，已被利用，已修复加固。
【过程】
1. 漏洞位置：xxx 功能 xxx 参数
2. 利用验证：payload：...（截图1）
3. 修复措施：...（复测失败截图2）
4. 加固清单：系统/中间件/数据库 各 N 条（截图3）
5. 应急排查发现：Webshell /var/www/x.php（截图4），已删除
6. 攻击时间线：10-20 09:12 注入探测 / 09:15 上传落地 / 09:18 外联（日志截图5）
【遗留与建议】未解决项+后续计划
```

## 五、常见失分点【背】

1. 只给结论不给截图——**没证据=没做**。
2. 加固只写"加强管理"这种空话——要写具体命令/配置。
3. 反制写"攻击回去"——合规红线，直接零分。
4. 修复不复测、加固不验证——闭环没走完。
5. 时间耗死在注入手工数列——超过 10 分钟换 sqlmap 或跳段。

## 六、高频考点提示

1. 五段式顺序必背，比赛和笔试都考"漏洞利用后紧接着该做什么"——答案就是**修复→加固→排查→溯源**。
2. 每段"证据三合一"：**payload+命令+结果截图**。
3. 报告结构：结论→过程→遗留，先结论后过程。
4. 全链条题的本质是把 06、07 篇串起来——那两篇背熟，这里只剩流程问题。
