压缩与解压缩命令

本篇整理 Linux 常用压缩/解压与归档备份工具：zip、gzip、bzip2、tar、dd、cpio，以及各自的最常用选项、示例和易错点。

zip / unzip

用于将文件或目录压缩/解压，默认生成 .zip 后缀包，类似于 Windows 的 WinZip。

zip [选项] 压缩文件名 需要压缩的文档列表
unzip [选项] 压缩文件名

zip 常用选项：

选项含义
-r递归压缩，含所有子目录
-d从压缩包内删除指定文件
-i "文件列表"只压缩列表内文件
-x "文件列表"压缩时排除指定文件
-u更新文件到压缩包
-m压缩后删除原始文件（移入包内）
-F尝试修复损坏压缩包
-T检查包内每个文件是否正确
压缩级别1~9 的数字，越大压缩率越高

unzip 常用选项：

选项含义
-x "文件列表"解压但不含指定文件
-t测试有无损坏，不解压
-v查看包详细信息，不解压
-n不覆盖已存在文件
-o覆盖已存在文件且不确认
-d 目录解压到指定目录

示例：

# 最高压缩级别压缩 /etc
zip -9r /opt/etc.zip /etc

# 压缩 /var 排除 *.log
zip -r /opt/var.zip /var -x "*.log"

# 从包内删除文件 / 更新文件
zip /opt/etc.zip -d etc/passwd
zip -u /opt/etc.zip /etc/inittab
zip -ru /opt/etc.zip /etc

# 解压到 /etc，排除 inittab，覆盖不确认
unzip -o /opt/etc.zip -x etc/inittab -d /etc

gzip / gunzip

压缩文件预设扩展名 .gz。gunzip 是 gzip 的硬链接，所以压缩、解压都能通过 gzip 实现。

⚠ 注意：gzip 只能压缩文件，不能压缩目录，即使指定目录，也只能压缩目录内的所有文件。

gzip [选项] 要压缩（解压）的文件
选项含义
-d解压
-r递归压缩目录及子目录下的所有文件
-t检查压缩文档完整性
-v显示文件名和压缩比
-l显示压缩信息（大小、压缩比、名称）
-num压缩比：-1/-fast 最低，-9/-best 最高，默认 6

示例：

gzip -9v /opt/etc.zip       # 生成 etc.zip.gz
gzip -l /opt/etc.zip.gz     # 查看压缩信息
gzip -d /opt/etc.zip.gz     # 解压，等价于 gunzip /opt/etc.zip.gz

bzip2 / bunzip2

类似 gzip，只能对文件压缩，不能压缩目录；生成 .bz2 后缀。bunzip2 是 bzip2 的软链接。

bzip2 [选项] 要压缩或解压的文件
选项含义
-d解压缩
-v显示详细信息
-k压缩/解压后保留原始文件（默认删除）
-f覆盖同名文件
-t测试 .bz2 完整性
级别1~9，越大压缩率越高

示例：

bzip2 -9vk /opt/etc.zip /opt/var.zip   # 最高压缩、保留原文件、显示详情
# 生成 etc.zip.bz2、var.zip.bz2

tar：归档打包

tar 是 Linux 最常用的归档工具，把文件/目录打成一个档案文件（不压缩）。

tar [主选项＋辅助选项] 文件或目录

主选项：-c 创建、-r 追加到末尾、-t 列出内容、-x 还原、-u 更新。

辅助选项：

选项含义
-z调用 gzip 压缩/解压
-j调用 bzip2 压缩/解压
-Z调用 compress 过滤
-f指定档案文件，必须是最后一个选项
-v显示归档过程
-p保持文件属性
-w还原时把所有文件时间设为当前
-N "yyyy/mm/dd"只打包指定日期之后的文件
--exclude file打包时不包含指定文件

⚠ 易错点：-f 之后不能再跟其他选项，-f 必须是 tar 命令的最后一个选项。

示例：

# 打包不压缩
tar -cvf /opt/etc.tar /etc

# 打包并压缩（gzip / bzip2）
tar -zcvf /opt/etc.tar.gz /etc
tar -jcvf /opt/etc.tar.bz2 /etc

# 查看压缩包内容
tar -ztvf /opt/etc.tar.gz
tar -jtvf /opt/etc.tar.gz

# 解压
cd /usr/local/src && tar -zxvf /opt/etc.tar.gz

# 保留权限打包
tar -zcvpf /opt/etc.tar.gz /etc

# 只解压包内某个文件（路径必须是 tvf 显示的完整路径）
cd /opt && tar -zxvf /opt/etc.tar.gz etc/inittab

# 只打包 2008/7/21 之后的文件
tar -N "2008/7/21" -zcvf log.tar.gz /var/log

# 打包多个目录，排除某个子目录
tar --exclude /home/ixdba -zcvf myfile.tar.gz /home/* /etc

# 打包并直接解压，不生成档案文件
cd /opt && tar -zcvf - /etc | tar -zxvf -

命名约定：.tar 表示 tar 打包、.gz 表示 gzip 压缩、.bz2 表示 bzip2 压缩，解压方式与压缩方式对应。

dd：转换/拷贝与设备备份

dd if="输入文件" of="输出文件" bs="块大小" count="块数量"
参数含义
if输入文件，可为设备（分区/整个磁盘）
of输出文件，也可为设备（磁盘/磁带）
bs一个块的大小，默认 512 bytes
count块的数量

示例：

# 备份单个文件
dd if=/etc/inittab of=/opt/inittab.bak
# 输出 3+1 records：3 个完整 512B 块 + 1 个未满 512B 的块

# 备份整个分区
dd if=/dev/sda2 of=/opt/sda2.back

# 恢复分区
dd if=/opt/sda2.back of=/dev/sda2

⚠ 易错点：

  1. 备份输出路径不能是源分区所在分区，否则永远备份不完。
  2. 恢复目标分区前先卸载该分区，恢复完成后再挂载。
  3. 恢复目标分区最好与备份分区大小一致：目标更大浪费空间，更小会提示空间不足。

cpio 归档

cpio 通过重定向方式打包/还原文件，可解压 .cpio 或 .tar 结尾的文件。它无法直接读取文件，需要完整路径，因此通常与 find 配合使用。

cpio [选项] > 文件名或设备
cpio [选项] < 文件名或设备
选项含义
-o打包文件输出到文件/设备
-i解包/还原
-t查看打包内容
-v显示打包文件名称
-d还原时自动建立目录
-c较新的存储方式
-BBlocks 增大到 5120B（默认 512B），加快存取

示例：

# 打包 /etc 下所有普通文件
find /etc -type f | cpio -ocvB > /opt/etc.cpio

# 备份整个系统到磁带
find / -print | cpio -covB > /dev/st0

# 查看磁带内容
cpio -icdvt < /dev/st0

# 还原备份（含绝对路径则恢复到绝对路径）
cpio -icduv < /opt/etc.cpio

cpio 还原路径由打包时用的是绝对还是相对路径决定：绝对路径恢复后自动回到绝对路径下，相对路径则回到相对路径。

小结

工具特性关键点
zip支持目录-r 递归、-x 排除
gzip只压缩文件gunzip 是硬链接、-9 最高
bzip2只压缩文件-k 保留原文件
tar归档不压缩-z 配 gzip、-j 配 bzip2、-f 必须最后
dd块级备份if/of/bs/count
cpio重定向归档常与 find 管道配合

日常最常用：tar -zcvf 打包压缩、tar -zxvf 解压；gzip -9 高压缩率；dd 做整盘/分区备份。
