命令的组合应用

本篇讲解 Linux 中通过管道 |、for 循环、awk、xargs、sort、uniq、join、paste 等组合命令解决实际运维问题的方法。命令组合是 Linux 运维进阶的核心能力。

查询每个进程的线程数

场景：服务器 CPU 飙升，top 显示 java 进程占 CPU 高，需要查看各 java 进程下线程数。

for pid in $(ps -ef | grep -v grep | grep "java" | awk '{print $2}'); do
  echo ${pid} > /tmp/a.txt
  cat /proc/${pid}/status | grep Threads > /tmp/b.txt
  paste /tmp/a.txt /tmp/b.txt
done | sort -k3 -rn

逐步拆解：

  1. ps -ef | grep -v grep | grep java | awk '{print $2}'：得到 java 进程的 PID 列表。
  2. echo ${pid} > /tmp/a.txt：把 PID 写入 a.txt。
  3. cat /proc/${pid}/status | grep Threads：读取该进程线程信息。
  4. paste /tmp/a.txt /tmp/b.txt：把两个文件按列拼接展示（PID + 线程数）。
  5. sort -k3 -rn：按第 3 列（线程数）降序排列，-k3 按第 3 列、-r 降序、-n 数字排序。

输出第一列为进程号，最后一列为线程数。

2. 检测并清理僵尸进程

查找僵尸进程（状态以 Z/z 开头）：

ps -e -o stat,ppid,pid,cmd | egrep '^[Zz]'

参数：-e 列出所有进程；-o 指定输出列（stat 状态、ppid 父进程 PID、pid 当前 PID、cmd 可执行文件）；egrep 正则工具；^[Zz] 表示第一字符是 Z 或 z（僵尸进程状态标记）。

批量清理（杀掉僵尸进程的父进程）：

ps -e -o stat,ppid,pid,cmd | grep -e '^[Zz]' | awk '{print $2}' | xargs kill -9

解析：

  • grep -e 等价于 egrep。
  • awk '{print $2}' 提取第 2 列（父进程 PID）。
  • xargs kill -9 把父进程 PID 作为参数传给 kill。

易错点：僵尸进程本身已是死进程，无法接收任何信号，直接 kill 杀不掉。杀掉其父进程后，僵尸进程变成孤儿进程，由 1 号进程（init/systemd）收养并周期调用 wait 清除。

3. 查看占用 CPU/内存最高的进程

查看占用 CPU 最高的前 10 个进程：

ps aux | head -1; ps aux | sort -rn -k3 | head -10
  • ps aux|head -1：取标题行（USER PID %CPU %MEM ...）。
  • ps aux|sort -rn -k3|head -10：a 全部进程、u 用户 ID、x 不以终端区分；sort -rn -k3 按第 3 列 %CPU 数值降序；head -10 取前 10。

查看占用内存最高的前 10 个进程：改为 -k4（%MEM 是第 4 列）：

ps aux | head -1; ps aux | sort -rn -k4 | head -10

4. 文件的连接、合并、排序、去重

join：按指定列连接两个文件

join 将两个文件中指定列内容相同的行连接起来。默认以空格分隔并比对第 1 个字段。

参数含义
-t指定分隔符
-i忽略大小写
-1第 1 个文件用哪个字段分析
-2第 2 个文件用哪个字段分析
join -t ':' -1 3 file1.txt -2 3 file2.txt

以 : 为分隔符，将 file1 第 3 列与 file2 第 3 列相同的行合并，相同字段移到每行最前。

paste：按列合并

paste 把每个文件以列对列方式合并，同一行贴在一起用 [tab] 分隔，比 join 简单：

paste file1.txt file2.txt

管道中 - 代表标准输入，可合并三份内容：

cat /etc/group | paste /etc/passwd /etc/shadow - | head -n 3

这里的 - 接收 cat /etc/group 送来的标准输入。

sort：排序

sort [-t 分隔符] [-kn1,n2] [-nru]
参数含义
-n按纯数字排序（默认字母序）
-r反向排序
-u相同数据仅显示一行（相当于 uniq）
-t分隔符，默认 [tab]
-k指定排序字段

示例：

# 默认按字母序
cat /etc/passwd | sort | head

# 按 ':' 第 3 列数值排序
cat /etc/passwd | sort -t ':' -k3 -n | head

uniq：去重

uniq 用于检查及删除相邻的重复行，常与 sort 配合。

参数含义
-c / --count每列旁显示重复次数
-d / --repeated仅显示重复的行

示例：

uniq ixdbafile1        # 删除相邻重复行
uniq ixdbafile1 -c     # 统计重复次数

易错点：uniq 只能处理相邻重复行。若重复行不相邻，uniq 失效（文件原样输出）。先用 sort 排序让重复行相邻，再管道给 uniq：

sort ixdbafile2 | uniq      # 去重
sort ixdbafile2 | uniq -d   # 只显示重复行

小结

场景命令组合
查进程线程数ps -ef + for + /proc/pid/status + paste + sort -k3 -rn
清僵尸进程ps -eo + grep + awk + xargs kill -9
CPU 占用 TOPps aux + sort -rn -k3 + head -10
内存占用 TOPps aux + sort -rn -k4 + head -10
按 key 合并文件join -t
按行合并paste（- 代表标准输入）
排序sort -t -k -n -r
去重sort + uniq

组合命令的核心是管道 | 把上一条输出作为下一条输入；xargs 负责把标准输入转成命令参数；awk 负责按列提取；sort/uniq 负责排序去重。掌握这四者的配合即可解决大部分文本与进程处理的组合需求。
