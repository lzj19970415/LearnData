系统维护篇

千锋 Linux 课件《学 Linux，掌握这 80 个命令就够了》第一篇《系统管理与维护命令》。本篇 17 个命令覆盖目录查看、时间管理、用户切换、登录审计、内存与进程监控，是日常运维与故障排查的基本功。

1. ls：列出目录内容

显示指定工作目录下的内容，列出工作目录所含的文件及子目录，类似 Windows 的 dir（Linux 也提供 dir 命令，可以替代 ls）。

ls [选项] [路径或文件]

常用选项：

选项含义
-a显示所有文件及子目录，包含隐藏文件（. 开头的为隐藏文档）
-d只显示目录列表，不显示文件
-l详细列出权限、使用者、大小等信息
-s在每个文件名后输出文件大小
-k以 KB 形式表示文件大小
-u以文件上次被访问的时间排序
-t以时间排序
-S以文件大小排序
-r反向排序
-R递归列出所有子目录下的文件
-o显示除组信息外的详细信息
-x按列输出，横向排序
-C按列输出，纵向排序
-Q输出的文件名用双引号括起来
-m横向输出文件名，以 , 作分隔符
-q用 ? 代替不可输出的字符
-pF文件名后附类型标记：* 可执行普通文件、/ 目录、@ 符号链接、| FIFOs、= 套接字

示例：

ls -l /home
# -rw-r--r--  1 root   root      0 Jul  7 22:39 db2
# drwx------  3 mysql  mysql 4096 Oct 10  2021 mysql
# drwx------  3 oracle oracle  4096 Oct 16  2021 oracle

ls -alF        # 所有文件（含隐藏）+ 详细信息 + 类型标记

ls -l 输出从左到右依次为：权限、硬链接数、属主、属组、大小、修改时间、名称。首字符 - 普通文件、d 目录、l 符号链接。

2. pwd：显示当前工作目录

pwd

执行后立刻得知目前所在目录的绝对路径。

3. cd：切换工作目录

cd [目录名]
格式说明
cd [目录]切换到指定目录（Linux 下文件和目录区分大小写）
cd 或 cd ~返回当前用户的默认工作目录（家目录），cd 与 ~ 之间有空格
cd ~用户名返回指定用户的家目录，~ 与用户名之间没有空格
cd .. 或 cd ../返回上级工作目录
cd /返回根目录
cd /usr/bin
pwd         # /usr/bin

cd ~oracle
pwd         # /home/oracle

4. date：显示 / 设置系统时间

显示或修改系统时间与日期。只有超级用户才能设置时间，一般用户只能查看。

date [选项] +时间格式

选项：

  • -s --set：设置系统时间
  • -d --date：显示描述的日期（如 "2 days ago"）

常用时间格式符：

格式含义
%H小时 00~23
%I小时 01~12
%k小时 0~23
%l小时 1~12
%M分钟 00~59
%S秒 00~59
%pAM（上午）/ PM（下午）
%rhh:mm:ss AM/PM
%T时间 hh:mm:ss
%a星期几
%b / %B月份简称 / 月份全称
%m月份 01~12
%d一个月的第几天
%Dmm/dd/yy
%xmm/dd/yyyy
%X相当于 %H:%M:%S
%Y / %y完整年份 / 年份后两位
%Z时区
%c日期时间完整组合（%a %d %b %Y %r %Z）

示例：

# 用指定格式显示日期时间
date '+This date now is:%x, time is now:%X'

# 设置系统时间（root）
date -s 20210715
date -s 17:25
date -s "20210715 17:25"     # 两步可合并

# 格式化输出
date '+%Y-%m-%d'              # 2021-07-15

# 显示两天前的日期
date -d "2 days ago" +%Y-%m-%d    # 2021-07-13

5. passwd：设置用户口令

passwd [用户名]
  • 普通用户修改自己的口令：直接 passwd，按提示连续输入两次新口令
  • root 修改某用户口令：passwd 用户名
  • root 修改自己：passwd 或 passwd root

6. su：切换用户身份

su [选项] [用户名]
选项说明
-加载目标用户的环境变量（推荐）
-l使目前 shell 成为目标用户默认 shell
-c改变身份执行一条指令后结束
-m切换身份但不改变环境变量
su -             # 普通用户切换为 root，输入 root 口令
su -c passwd     # 以 root 身份改密码，执行完自动退回原用户

关键区别：su 与 su - 都能切换为 root，但不加 - 不加载 root 环境变量，某些指令会提示 command not found。日常运维请用 su -。

7. clear：清屏

clear

8. man：命令帮助手册

man [命令名称]
man ls

man 5 crontab 这类写法用于查看配置文件格式的手册（分节查询）。

9. who：显示当前登录用户

who [选项] [file]

一般输出格式：名称 [状态] 线路 时间 [活动] [进程标识]（主机名）

  • 名称：用户登录名
  • 状态：线路是否对所有用户可写
  • 线路：如 pts/1、pts/2，可在 /dev 目录中找到
  • 时间：用户登录系统的时间
  • 活动：最后一次活动距今时间；. 表示一分钟内有活动；静止超 24 小时或开机后未使用标记为 old
  • 进程标识：用户登录 shell 的 PID
  • 主机名：登录到本机的客户端标识

常用选项：

选项说明
-a列出所有信息（相当于所有选项）
-b列出系统最近启动时间日期
-l列出所有可登录终端信息
-m仅当前终端信息（等价 who am i）
-q列出本地用户和用户数清单
-r显示当前系统运行级别
-s仅显示名称、线路、时间（默认输出）
-u用户名、终端、登录时间、活动、进程标识
-T / -w终端状态：+ 任何人可写，- 仅 root/所有者可写，? 线路故障

who 通常通过 /var/run/utmp 文件获取信息；若指定 file 参数，则读取指定文件。

10. w：登录用户 + 正在做什么

w [选项] [用户]
选项含义
-h不显示输出信息的标题
-l长格式输出
-s短格式输出（不显示登录时间、JCPU、PCPU）
-V显示版本信息

第一行输出：当前系统时间、开机至今运行时长、登录用户数、系统平均负载（1 分钟、5 分钟、15 分钟）。

字段含义：

  • USER：登录系统的用户
  • TTY：用户使用的终端名称
  • FROM：从哪里登录进来（远程主机 IP 或主机名）
  • LOGIN@：登录日期和时间
  • IDLE：某程序上次从终端执行至今的空闲时间
  • JCPU：该终端所有进程及子进程占用系统的总时间
  • PCPU：当前活动进程使用的系统时间
  • WHAT：当前用户执行的进程名称和选项

11. uname：系统信息

uname [选项]
选项含义
-a显示操作系统全部信息
-m显示 CPU 类型（32 位还是 64 位系统）
-n显示操作系统主机名
-s显示操作系统类型
-r显示操作系统内核版本
uname -a
# Linux centos7.9 3.10.0-1160.el7.x86_64 ... x86_64 GNU/Linux

12. uptime：运行时间与负载

输出系统任务队列信息：当前时间、开机至今运行时间、在线用户数、系统平均负载。

uptime
# 16:03:08 up 4 days, 1:49, 2 users, load average: 0.12, 0.20, 0.17

解读：现在 16:03:08，系统已运行 4 天 1 小时 49 分，2 个用户在线，1/5/15 分钟平均负载为 0.12、0.20、0.17。

经验（补充）：负载长期接近或超过 CPU 核心数，说明系统繁忙，需结合 top 定位进程。

13. last：历史登录记录

列出目前与过去登入系统的用户相关信息，默认读取 /var/log/wtmp 文件。

last [选项] [-n 显示列数]
选项含义
-a登入的主机名或 IP 显示在最后一行
-R不显示登入的主机名或 IP
-x显示系统关机、重新开机以及执行等级的改变信息
-n设置列出名单的显示列数
-d将 IP 地址转换成主机名称
last -n 10        # 最近 10 条登录记录
last -x           # 含关机/重启记录（排查是否被人重启过）
last root         # 只看 root 的登录

14. dmesg：开机信息

内核将开机信息存储在系统缓冲区（ring buffer）中，开机后来不及查看可用 dmesg 回看；也可以在 /var/log/ 目录中查看 dmesg 文件。

dmesg [选项]
选项含义
-c显示开机信息后清除 ring buffer 信息
-s设置缓冲区大小，默认 8192
-n设置记录信息的层级
dmesg | grep -i error       # 快速过滤硬件/驱动报错（补充用法）
dmesg | tail                # 看最近的内核消息

15. free：内存状态

显示系统内存状态，包括物理内存、虚拟内存、共享内存和系统缓存。

free [选项] [-s 间隔秒数]
选项含义
-b以 Byte 为单位显示
-k以 KB 为单位显示
-m以 MB 为单位显示
-t显示内存总和列
-s N每隔 N 秒持续显示内存使用情况
-o不显示系统缓冲区列
free -m
# 总物理内存 64GB，已用 2467MB，空闲 56538MB
# swap 交换分区 32GB，尚未被使用

解读要点（补充）：Linux 会把空闲内存拿去做 buffers/cache 提升性能，所以 free 偏小不一定是内存不足；新版本看 available 字段才是真正可用内存。

16. ps：进程快照

显示系统进程在瞬间的运行动态。

ps [选项]
选项含义
a显示所有用户的进程（含完整路径）
x显示所有系统程序（包括没有终端的程序）
u显示使用者名称和起始时间
f详细显示程序执行的路径群
c只显示进程名称，不显示完整路径
e将除内核进程外所有进程的信息写到标准输出

默认输出字段：PID（进程号）、TTY（所属终端）、TIME（累计 CPU 时间）、CMD（命令行）。

最常用组合：

ps -ef             # 全格式列出所有进程
ps aux             # BSD 风格，含 %CPU、%MEM 列
ps -ef | grep sshd # 过滤指定进程

ps 是最基本、最强大的进程查看命令：可确定哪些进程在运行、占用多少资源、运行状态是否正常、有没有僵死现象等。最常用选项组合为 ps -ef、ps aux。

17. top：实时进程监控

类似 Windows 任务管理器，实时显示各进程资源占用状况，可按 CPU、内存、执行时间排序，并支持交互式设定。

top [选项]
选项含义
-d指定两次信息刷新的时间间隔
-i不显示闲置或僵死进程
-c显示进程的整个命令路径
-s安全模式运行（取消交互式指令）
-b分屏显示输出，结合 -n 可把信息输出到文件
-n更新 N 次后退出

交互式命令（top 运行中按单个字母）：

按键作用
h / ?显示帮助
k终止一个进程（输入 PID）
i忽略闲置/僵死进程（开关）
s改变刷新间隔（默认 5 秒，过小会加大负载）
o / O改变显示列顺序（小写 a~z 右移、大写 A~Z 左移，回车确定）
f / F添加或删除显示列（回车确定）
m切换显示内存信息
t切换显示进程和 CPU 状态信息
r重新设置进程优先级（输入 PID 与 nice 值，默认 10）
l切换显示平均负载和启动时间
q退出 top
c切换完整命令行 / 命令名
M按驻留内存大小排序
P按 CPU 使用百分比排序
T按时间/累计时间排序
S切换累计模式
W当前设置写入 ~/.toprc

输出分两大区：

（1）统计信息区（前 5 行）

  • 第 1 行任务队列：当前时间（13:29:02）、up 运行时长（3 days, 23:15）、users 用户数、load average 平均负载（1/5/15 分钟）
  • 第 2 行进程：Tasks total 总数 / running 运行 / sleeping 休眠 / stopped 停止 / zombie 僵死
  • 第 3 行 CPU：us 用户进程占用、sy 系统进程占用、ni 改过优先级的进程占用、id 空闲、wa 等待 I/O 占用
  • 第 4~5 行内存：Mem total/used/free/buffers；Swap total/used/free/cached

（2）进程信息区

列含义
PID进程 id
USER进程所有者
PR进程优先级
NInice 值（负值高优先级，正值低优先级）
VIRT虚拟内存总量（VIRT = SWAP + RES）
RES未被换出的物理内存（RES = CODE + DATA）
SHR共享内存大小
S状态：D 不可中断睡眠、R 运行、S 睡眠、T 跟踪/停止、Z 僵死
%CPU上次更新到现在 CPU 时间占用百分比
%MEM进程占用物理内存百分比
TIME+进程使用的 CPU 时间总计（1/100 秒）
COMMAND正在运行的命令名或路径

补充：进程终止命令（配合 ps / top 使用）

kill PID          # 默认发 15（TERM），请求正常终止
kill -9 PID       # 强制终止（进程无法正常退出时使用）
killall 进程名     # 按名称终止进程
pkill -u 用户名    # 按条件终止

僵尸进程（Z 状态）用 kill 无效，需处理其父进程；先 kill（TERM）再考虑 kill -9，给进程保存数据的机会。

要点速记

  • su - 与 su 的区别在是否加载环境变量，运维统一用 su -
  • 时间设置仅 root 可做：date -s "20210715 17:25"；date -d "2 days ago" 算历史日期
  • 平均负载三数值对应 1/5/15 分钟；与 CPU 核心数对比判断压力
  • free -m 看内存：buffers/cache 可回收，available 才是真正可用
  • 进程排查三板斧：ps -ef / ps aux / top（P 按 CPU 排序、M 按内存排序、k 杀进程）
  • last 读 /var/log/wtmp（历史登录），who 读 /var/run/utmp（当前登录）
  • dmesg 看内核开机信息，硬件排障第一步
