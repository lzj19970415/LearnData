磁盘管理与维护命令

本篇整理 Linux 磁盘管理命令，覆盖空间查看、分区检查与修复、挂载/卸载、硬件与时间信息查询、分区格式化与交换区管理。适用于日常运维与磁盘故障排查。

df：查看磁盘空间占用

df [选项]
选项含义
-h以易读格式输出（kB/MB/GB）
-k以 kB 为单位
-m以 MB 为单位
-a列出所有分区（含 0 大小）
-i列出 inodes 信息
-T显示文件系统类型

示例：

df -hT                # 查看分区 + 文件系统类型
df -ihT               # 查看 inode 信息

从 df -hT 可以看到每种文件系统的总大小、已用、剩余、占用百分比，以及文件系统类型（ext3、ext4、tmpfs、xfs 等）。

du：查看文件/目录占用空间

du [选项] 文件或目录
选项含义
-s显示整个目录大小（kB）
-b以字节为单位
-sh以易读格式显示（300MB、1.2GB）
-sm以 MB 为单位

示例：

du -sh ./*        # 当前目录下各文件大小
du -sh /etc       # 查看 /etc 总大小

fsck：检查并修复文件系统

fsck [选项] [-t 文件系统类型] [设备名]
选项含义
-a自动修复，无提示
-r交互式修复，逐个确认
-A按 /etc/fstab 检查全部文件系统
-T不显示标题
-V显示执行过程
-N不执行，仅列出将执行的动作

⚠ 易错点：执行 fsck 修复某个文件系统前，该磁盘分区必须处于卸载状态。挂载状态下修复极不安全，可能破坏数据甚至损坏磁盘。

示例：交互式修复 /dev/sda10（ext4），显示详细过程：

fsck -rV -t ext4 /dev/sda10

修复经历 5 个检查阶段（inodes、目录结构、目录连通性、引用计数、组摘要），发现错误会提示是否修复，按 y 确认，其他键跳过。发现孤立文件会询问是否找回，找回的文件放在 lost+found 目录，用 inode 号命名；可用 file 命令判断类型找到丢失文件。

sync：强制写回内存数据到磁盘

Linux 修改过的数据会先缓存在内存，等待适当时候再写盘，以提升读写效率。系统默认每隔 3 秒自动执行一次 sync，正常关机也会执行。

sync

非法关机无法及时把内存数据写回磁盘，可能造成数据丢失或文件损坏。因此 Linux 系统正常关机非常重要。

eject：退出抽取式设备

用于退出光驱、磁带等；若设备已挂载则先卸载再退出。

eject [选项] 设备名

常用选项：-c 光驱编号 多光驱指定、-d 显示默认设备、-f 软盘、-q 磁带、-r 光盘、-t 关闭托盘、-n 显示设备文件路径。

示例：

eject --noop floppy   # 显示设备路径 /dev/fd0
eject -n cdrom        # 显示设备路径 /dev/hda
eject /tmp            # 卸载 /tmp 分区

mount / umount：挂载 / 卸载

mount [选项] [-L 标签] [-o 选项] [-t 文件系统类型] [设备名] [挂载点]
umount [挂载点]

常用选项：-a 加载 /etc/fstab 中所有设备；-n 不记录到 /etc/mtab；-r 只读；-w 可读写（默认）；-f/-v 仅查看挂载状态。

-o 常见选项：async/sync 异步/同步 IO；atime/noatime 是否更新 inode 存取时间；auto/noauto 是否可用 -a 加载；exec/noexec 是否可执行二进制；dev/nodev 是否读设备文件；suid/nosuid 是否开启设置位；user/nouser 普通用户是否可加载；ro/rw 只读/读写；remount 重新加载；defaults 默认选项（rw、suid、dev、exec、auto、nouser、async）；iocharset、codepage 指定字符集/内码表。

-t 文件系统类型：ext4/xfs（Linux 常用）、msdos、vfat、nfs（网络文件系统）、iso9660（光盘）、ntfs。

示例：

# 挂载 ISO 镜像（loop 把镜像当分区挂载）
mount -o loop -t iso9660 /iso/CentOS-7-x86_64-DVD.iso /ixdba

# 挂载 Windows D 盘（FAT，支持中文）
mount -t vfat -o codepage=936,iocharset=cp936 /dev/hda3 /mnt/d

# 以只读方式挂载 NFS
mount -t nfs -o ro 192.168.60.133:/home/ixdba /mnt/nfs

挂载成功后通过访问挂载点目录即可读取设备内容。

lspci：查看 PCI 设备

显示所有 PCI 总线及设备信息（网卡、存储等多为 PCI 总线）。

lspci [参数]

常用：-n 数字显示厂商/设备代码、-t 树状结构、-b 总线中心视图、-s 指定总线插槽、-m 机器可读。

示例：

lspci
lspci -t      # 树状显示

hwinfo：硬件信息查询

类似 lshw，可详细或简要报告硬件信息。部分命令需 root 权限。

hwinfo [参数]

常用：--short 简要信息、--log 写入 log、--cpu CPU 信息、--usb USB 设备、--storage 硬盘信息、--netcard 网卡。

示例：

hwinfo --short
hwinfo --short --cpu      # 查看 CPU
hwinfo --short --storage  # 查看硬盘

clock：调整 RTC 硬件时钟

clock 调整电脑内建硬件时间（RTC），可显示当前时刻、调整硬件时钟、同步系统/硬件时钟。

clock [参数]

常用：--adjust 自动调整、--hctosys 硬件时钟同步到系统时钟、--systohc 系统时间写入硬件时钟、--show 显示硬件时钟、--set --date 设置硬件时间、--utc 以 UTC 处理、--test 仅测试。

示例：

clock --hctosys     # 同步系统时钟

fdisk：磁盘分区工具

fdisk [参数]

常用：-l 列出分区表、-s 输出分区大小（区块单位）、-u 以分区数目表示起始地址、-b 指定分区大小、-v 版本。

示例：

fdisk -l          # 查看所有分区
fdisk /dev/sdb    # 选择磁盘进行分区

mkfs：建立文件系统

mkfs（make file system）在特定分区上建立文件系统。

mkfs [-V] [-t fstype] [-c] filesys [blocks]

参数：-V 详细模式、-t 指定文件系统类型（ext3/ext4/xfs）、-c 制作前检查坏轨、-l bad_blocks_file 记录坏轨 block。

示例：

mkfs -V -t ext4 -c /dev/sda5   # 建 ext4 并检查坏轨
mkfs -t xfs /dev/sda6            # 等价于 mkfs.xfs /dev/sda6

swapon：激活交换空间

Linux 内存管理必须使用交换区来建立虚拟内存，swapon 用于激活交换空间。

swapon [参数]

常用：-a 启动 /etc/fstab 中所有 swap 设备、-p 设置优先顺序、-s 显示交换区使用情况。

示例：

swapon -s     # 查看交换区使用情况
swapon -a     # 自动加载所有 swap

小结

命令作用关键参数
df磁盘空间-hT、-i
du目录占用-sh
fsck检查修复文件系统需先卸载
sync内存写回磁盘系统默认 3 秒
mount/umount挂载/卸载-t、-o、loop
fdisk分区-l
mkfs建立文件系统-t
swapon激活交换分区-a、-s

关键易错点：fsck 前必须卸载分区；dd/恢复前先卸载目标分区；mkfs 会格式化清空数据，务必确认分区；sync 强调正常关机的重要性。
