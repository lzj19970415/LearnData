防火墙·中级

网络设备网络防火墙安全约 3012 字大约 10 分钟

中级篇在初级基础上深入：地址组/服务组/时间段、NAT 全家族（Easy-IP/地址池/NAT Server）、策略路由分流、用户认证、双机热备（HRP）与日志审计。学完能独立完成企业级上网策略、服务器映射、链路分流的配置与排障。

一、安全策略进阶

1.1 地址组（Address Set）

当源/目的地址很多时，一条条写 IP 太痛苦，用地址组一次定义、处处引用。

# 定义地址组 office_net，包含两个网段
[Huawei] ip address-set name office type object
[Huawei-address-set-office] address 0 network 192.168.1.0 24
[Huawei-address-set-office] address 1 network 192.168.2.0 24
[Huawei-address-set-office] quit

# 在安全策略中引用
[Huawei] security-policy
[Huawei-policy-security] rule name allow_office_out
[Huawei-policy-security-rule-allow_office_out] source-address address-set office
[Huawei-policy-security-rule-allow_office_out] source-zone trust
[Huawei-policy-security-rule-allow_office_out] destination-zone untrust
[Huawei-policy-security-rule-allow_office_out] action permit

华三 Comware V7 对应写法：object-group ip address office → 里面 network 192.168.1.0 24，策略里用 source-address object-group office 引用。

1.2 服务组（Service Set）

只允许访问固定的几个端口时，可以打包成服务组：

[Huawei] ip service-set name web_and_ssh type object
[Huawei-service-set-web_and_ssh] service 0 protocol tcp destination-port 80
[Huawei-service-set-web_and_ssh] service 1 protocol tcp destination-port 443
[Huawei-service-set-web_and_ssh] service 2 protocol tcp destination-port 22
[Huawei-service-set-web_and_ssh] quit

[Huawei] security-policy
[Huawei-policy-security] rule name dmz_web_access
[Huawei-policy-security-rule-dmz_web_access] service service 0
[Huawei-policy-security-rule-dmz_web_access] action permit

1.3 时间段（time-range）

上班时间才能访问的端口/服务，用时间段限定：

# 定义工作时间段：周一~周五 08:00~18:00
[Huawei] time-range worktime 08:00 to 18:00 working-day
[Huawei] time-range worktime2 start 09:00 end 12:00 weekly saturday   # 周六上午

# 在策略里引用
[Huawei-policy-security] rule name office_web
[Huawei-policy-security-rule-office_web] service tcp destination-port 443
[Huawei-policy-security-rule-office_web] time-range worktime
[Huawei-policy-security-rule-office_web] action permit

华三 time-range 语法几乎相同：time-range worktime 9:00 to 18:00 working-day。

1.4 组合示例：工作日限时放行

完整例子：只允许办公室网段在工作时间访问外网 80/443：

ip address-set name office type object
 address 0 network 192.168.0.0 24
quit
ip service-set name http_https type object
 service 0 protocol tcp destination-port 80
 service 1 protocol tcp destination-port 443
quit
time-range worktime 08:00 to 18:00 working-day
quit

security-policy
 rule name office_out_worktime
  source-zone trust
  destination-zone untrust
  source-address address 0
  service http_https
  time-range worktime
  action permit
 quit
quit

1.5 会话表与会话老化

防火墙是状态检测设备：第一个包过策略后建立会话，后续双向流量直接查会话表，不再逐条比对策略。

# 查看当前会话
[Huawei] display firewall session table

# 查看会话统计（总数、协议分布）
[Huawei] display firewall session statistics
协议默认老化时间（华为）说明
TCP1800 秒连接关闭后进入 TIME_WAIT 才释放
UDP120 秒无连接，超时未通自动清
ICMP10 秒ping 流量老化快

改老化时间：

[Huawei] session aging-time tcp 3600       # TCP 改成 1 小时
[Huawei] display session aging-time        # 查看

华三 Comware：[H3C] session aging-time tcp 3600，display session aging-time；查看会话 display session table。 运维要点：NAT + 长连接业务（数据库、心跳）经常遇到"几分钟就断"，多半是会话老化太短或 NAT 映射超时，调大即可。

二、NAT 与防火墙

2.1 三类 NAT 总览

类型作用方向命令入口
源 NAT内网地址伪装成公网地址（上网）内→外nat-policy 的 action source-nat
目的 NAT（NAT Server）公网地址映射到内网服务器外→内nat server
双向 NAT内网通过公网地址访问内部服务器双向nat server + 源/目的转换结合

2.2 Easy-IP（最简单源 NAT）

使用出口接口的公网 IP 直接伪装，适合单公网 IP 的小型环境：

[Huawei] nat-policy
[Huawei-policy-nat] rule name nat_easyip
[Huawei-policy-nat-rule-nat_easyip] source-zone trust
[Huawei-policy-nat-rule-nat_easyip] destination-zone untrust
[Huawei-policy-nat-rule-nat_easyip] action source-nat easy-ip

2.3 地址池 NAT（多公网 IP）

运营商给了 2~8 个公网 IP，用地址池做出口（可 NAT Server 复用其中地址）：

# 定义公网地址池
[Huawei] nat address-group 1
[Huawei-address-group-1] section 202.100.10.10 202.100.10.20
[Huawei-address-group-1] quit

# 策略里引用
[Huawei] nat-policy
[Huawei-policy-nat] rule name nat_pool
[Huawei-policy-nat-rule-nat_pool] source-zone trust
[Huawei-policy-nat-rule-nat_pool] destination-zone untrust
[Huawei-policy-nat-rule-nat_pool] action source-nat address-group 1
[Huawei-policy-nat-rule-nat_pool] quit

华三：nat outbound 2000 address-group 1（先写 ACL 定义内网段），或 nat easy-ip。

2.4 NAT Server（服务器映射/目的 NAT）

外网访问内网 Web 服务器：公网 IP 202.100.10.10:80 → 内网 192.168.1.10:80：

[Huawei] nat server name web_server protocol tcp
  global 202.100.10.10 80 inside 192.168.1.10 80
[Huawei] quit

查看与验证：

[Huawei] display nat server
[Huawei] display nat session

华三 Comware：nat server protocol tcp global 202.100.10.10 80 inside 192.168.1.10 80（一样）。

2.5 防火墙 NAT 与路由 NAT 的区别（常考）

维度路由器 NAT防火墙 NAT
与安全策略的关系NAT 独立工作，不关心安全必须配合安全策略，NAT 后仍要过策略
会话表只有简单 NAT 表项状态会话表，NAT 与安全联动
攻击防护无可对 NAT 后的流量做入侵检测/防病毒
配置方式nat outbound 在接口上nat-policy 按区域+地址条件匹配

一句话：防火墙里 NAT 和策略是两条独立流水线，流量先查 NAT（转换地址）再查安全策略（决定放行），两者都要配对才通。

三、策略路由（分流上网）

3.1 为什么需要策略路由

普通路由表只有一个"下一跳"，而策略路由（PBR）可以按源/目的地址、应用、区域决定走哪条出口。典型场景：

  • 视频会议流量走专线（低延迟）
  • 普通上网流量走普通宽带
  • 两条专线按目的地址分流（电信流量走电信、移动流量走移动）

3.2 华为策略路由配置

需求：内网 192.168.10.0/24 访问 10.0.0.0/8 走专线 A（下一跳 202.1.1.1），其余走默认路由。

[Huawei] policy-route
[Huawei-policy-route] rule name pbr1
[Huawei-policy-route-rule-pbr1] source-zone trust
[Huawei-policy-route-rule-pbr1] source-address 192.168.10.0 24
[Huawei-policy-route-rule-pbr1] destination-address 10.0.0.0 8
[Huawei-policy-route-rule-pbr1] action next-hop 202.1.1.1
[Huawei-policy-route-rule-pbr1] quit
[Huawei-policy-route] quit

3.3 与 NAT 配合

PBR 只决定"走哪条路"，NAT 仍要按 nat-policy 匹配源 NAT。注意：NAT 优先级高于 PBR，NAT 已转换的流量 PBR 可能不识别原始源地址，此时用 NASC（NAT 会话控制）的 nat-policy 中 no-reverse 或对 PBR 配置 route 参数，运维上最稳妥的方式是 PBR 里 source-zone 直接用区域，避免叠加 NAT 后源地址漂移问题。

华三 Comware PBR：policy-based-route 在接口下发，语法 policy-based-route pbr1 permit node 10 + if-match acl 3000 + apply next-hop，最后接口下 ip policy-based-route。思路一致、命令组织不同。

四、用户认证（接入控制）

4.1 为什么要用户认证

策略只有"IP 维度"，但人是会换 IP 的。用户认证让策略基于"身份"（用户名/用户组）而不是 IP，适合访客上网审计、移动办公接入。

4.2 本地用户

# 创建用户（默认域 c.com）
[Huawei] user-manage
[Huawei-user-manage] create user name zhangsan
[Huawei-user-manage] create user name zhangsan ?   # 设置密码

实际华为命令（常用方式）：

[Huawei] aaa
[Huawei-aaa] local-user zhangsan password cipher Huawei@123
[Huawei-aaa] local-user zhangsan service-type admin
[Huawei-aaa] local-user zhangsan privilege level 15
[Huawei-aaa] quit

4.3 认证策略（对用户启用 Portal / 认证）

[Huawei] auth-policy
[Huawei-policy-auth] rule name auth_policy
[Huawei-policy-auth-rule-auth_policy] source-zone untrust
[Huawei-policy-auth-rule-auth_policy] action auth
[Huawei-policy-auth-rule-auth_policy] quit

真实项目中常用 Portal 认证（弹网页输入账号密码），配置为 user-manage 域 + Portal 服务器（内置或外置）+ 认证策略，接入用户会重定向到认证页面。

4.4 Radius（对接企业统一账号）

[Huawei] radius-server template radius1
[Huawei-radius-radius1] radius-server authentication ip 10.10.10.10 1812
[Huawei-radius-radius1] radius-server shared-key cipher Secret@123
[Huawei-radius-radius1] quit
[Huawei] aaa
[Huawei-aaa] radius-server radius1

4.5 基于用户的策略

认证通过后，策略可以按"用户组"放行：

[Huawei] security-policy
[Huawei-policy-security] rule name user_group_1
[Huawei-policy-security-rule-user_group_1] source-user-group user_group_1
[Huawei-policy-security-rule-user_group_1] destination-zone untrust
[Huawei-policy-security-rule-user_group_1] action permit

华三：认证配置入口在 auth-policy 与 security-policy，用户域 domain，RADIUS 在 radius scheme，命令风格相似。

五、双机热备（HRP）

5.1 为什么需要双机

防火墙是单点故障高发点，主备两台，主挂了自动切备，业务中断秒级。华为 USR 用 HRP（华为备份协议） 做主备同步。

5.2 主备模式原理

              Internet
                  |
            [FW-A 主] ──心跳口── [FW-B 备]
            (VIP: 202.100.10.1)      (同步配置+会话)
                  |
              内网交换机
  • 双机跑 VRRP 虚拟出一个网关，谁主谁承载流量
  • 主的配置、会话、NAT 表通过心跳口实时同步到备机
  • 主挂掉，备机 1 秒内接管，用户无感知

5.3 华为 USG 双机热备配置

主设备（FW-A）：

# 心跳口
interface GigabitEthernet1/0/10
 ip address 10.0.0.1 30
quit

# 开启 HRP
[Huawei] hrp enable
[Huawei] hrp interface GigabitEthernet1/0/10 remote 10.0.0.2

备设备（FW-B）：

interface GigabitEthernet1/0/10
 ip address 10.0.0.2 30
quit

hrp enable
hrp interface GigabitEthernet1/0/10 remote 10.0.0.1
hrp standby-device       # 声明自己是备机

5.4 需要同步的内容

内容同步方式说明
配置默认同步主配置自动备份给备
会话表配置 hrp session 同步主备切换后连接不断
NAT 表随会话同步已建立会话不重建
路由同步保证备机路由与主一致

5.5 验证

[Huawei] display hrp state        # 查看主备状态：ACTIVE / STANDBY
[Huawei] display hrp interface
[Huawei] display hrp 命令         # 会话同步统计

华三 SecPath 双机热备两种实现：IRF 虚拟化（两台逻辑合一，推荐新部署）或 HA 主备（会话同步 + VRRP），配置命令与华为 HRP 不同，但原理完全一致——"配置 + 会话 + 路由三同步"。

六、日志与审计

6.1 日志分类

类型说明用途
系统日志启动、登录、配置变更审计
安全日志策略命中、攻击检测、防病毒安全运维
会话日志每条会话的开始/结束流量分析
操作日志Web 界面操作记录管理员审计

6.2 日志发送到服务器（Syslog）

企业要求日志留存 ≥ 6 个月，通常把日志发到集中日志服务器：

[Huawei] info-center enable
[Huawei] info-center loghost 10.168.1.100            # 日志服务器 IP
[Huawei] info-center loghost 10.168.1.100 facility local5

华三 Comware 同款命令：info-center loghost 10.168.1.100。

6.3 查看登录日志

[Huawei] display logbuffer                     # 内存日志缓冲
[Huawei] display logbuffer | include login     # 过滤登录事件

6.4 查看攻击日志

# 查看攻击检测记录
[Huawei] display firewall attack-log

# 实时监控攻击告警
[Huawei] display firewall log 5
# 命令行查看防火墙检测攻击信息
[Huawei] display firewall detect-result

攻击日志是安全运维的"报警器"：看到大量 SYN Flood、Port Scan 记录，说明正在被扫描或攻击，配合下文高级篇的 DDoS 防护功能处置。

6.5 Web 界面监控（日常最快）

  • 首页仪表盘：实时流量、会话数、CPU/内存
  • 监控 → 会话：查看当前所有会话与连接
  • 监控 → 日志：筛选安全事件
  • 报表：按用户/应用/时段的流量 TOP 报表，常用于月度安全汇报

6.6 会话表进阶分析

[Huawei] display firewall session table verbose

输出里重点看：sip/dip、sport/dport、Nat 状态。能回答"这个连接到底走了哪个接口、是否做了 NAT"——排障时一锤定音。
