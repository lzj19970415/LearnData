防火墙·初级

网络设备网络防火墙安全约 3202 字大约 11 分钟

面向运维新手的防火墙入门笔记，以华为 USG 防火墙（VRP 命令）为主，华三 SecPath（Comware 命令）差异处用括号标注。学完本节能独立完成：接口/区域配置、放行策略配置、内网上网和访问 DMZ 服务器的基本组网。

一、防火墙是什么

1.1 一句话理解

防火墙是网络边界上的安全检查站：所有进出网络的流量都必须经过它，由它根据"允许/拒绝"规则决定放行还是拦截。它把网络划分成"可信区"和"不可信区"，是内网安全的第一道大门。

1.2 防火墙的三个发展阶段

代际名称核心机制局限
第一代包过滤防火墙只看报文的五元组（源IP/目的IP/源端口/目的端口/协议），一条条静态规则比对不认状态，回包流量也得配规则；配太多规则容易出错，攻击难防
第二代状态检测防火墙维护会话表（连接状态），只检查第一个包，回包自动匹配会话放行只看"谁到谁、什么端口"，不看内容，无法识别应用层攻击
第三代下一代防火墙 NGFW在状态检测基础上叠加应用识别、用户识别、内容检测（IPS/防病毒/URL过滤等）处理性能要求高，需要正确配置检测策略

现代企业/运营商在用的华为 USG、华三 SecPath 都属于 NGFW（下一代防火墙）：既管"五元组"，又能"认出这是微信还是迅雷、有没有带病毒"。

1.3 防火墙在网络安全中的位置

典型的边界防护拓扑：

        Internet
            |
         [边界防火墙]   ← 网络安全的第一道关口
            |
        [核心交换机]
         /        \
    [服务器区]    [办公区]
  • 边界防火墙：内网 ↔ 互联网之间，防外部攻击、做 NAT 上网
  • 内网防火墙：办公区 ↔ 服务器区（DMZ）之间，控制东西向访问
  • 主机防火墙（如 Windows 防火墙）：最后一道防线

华三 SecPath 与华为 USR 定位相同，都是运营商/政企常用的边界防护设备。本笔记以华为命令行（VRP 平台）为主，两者命令差异会逐步标注。

二、华为 USG 防火墙基础

2.1 登录方式

方式用途场景
Console 线首次上架、恢复密码必须掌握
Web 管理界面图形化配置、监控、日志查看日常运维最常用
SSH/Telnet远程命令行管理批量操作、脚本化

2.2 首次登录与 Web 管理

  1. Console 连接后开机，默认用户名 admin、默认密码在设备背面标签上（常见 Admin@123），首次登录强制改密。
  2. 给管理接口配 IP 后，浏览器访问 https://<管理口IP>:8443（默认端口 8443，HTTP 是 1000+ 端口，不同型号有差异）。
  3. Web 界面要点：策略配置、NAT 配置、会话监控、日志中心四个菜单是运维高频入口。

华三 SecPath：默认管理 IP 是 192.168.0.1/24，Web 端口默认 8443（部分版本为 8080）。

2.3 命令行基础

华为 VRP 命令系统三视图切换：

<Huawei> system-view          # 从用户视图进入系统视图
[Huawei] interface GigabitEthernet1/0/0   # 进入接口视图
[Huawei-GigabitEthernet1/0/0] quit        # 返回上一级
[Huawei] display current-configuration    # 查看当前生效配置
[Huawei] save                             # 保存配置

关键技巧：

  • ? 随时查看该命令下的可选参数
  • Tab 键补全命令；dis 开头是 display 的缩写
  • system-view → interface xxx → 配置 → quit → save 是一天到晚的循环

2.4 接口配置（三层接口 + IP）

system-view
[Huawei] sysname USG-FW-A            # 改设备名
[Huawei] interface GigabitEthernet1/0/0   # 接内网
[Huawei-GigabitEthernet1/0/0] ip address 192.168.1.254 255.255.255.0
[Huawei-GigabitEthernet1/0/0] quit
[Huawei] interface GigabitEthernet1/0/1   # 接外网
[Huawei-GigabitEthernet1/0/1] ip address 202.100.10.1 255.255.255.0
[Huawei-GigabitEthernet1/0/1] quit

注意：接口配完 IP 后不会自动生效业务，必须把接口加入安全区域并配置安全策略，否则默认丢包——这是防火墙与交换机的最大不同。

2.5 接口 VLAN 配置

防火墙上接口可以工作在二层（接内网交换机做 VLAN 汇聚）或三层（路由口）模式：

[Huawei] vlan batch 10 20              # 批量创建 VLAN
[Huawei] interface GigabitEthernet1/0/2    # 面向内网交换机的口
[Huawei-GigabitEthernet1/0/2] port link-type trunk
[Huawei-GigabitEthernet1/0/2] port trunk allow-pass vlan 10 20
[Huawei-GigabitEthernet1/0/2] quit
[Huawei] interface Vlanif10               # VLAN 三层接口
[Huawei-Vlanif10] ip address 192.168.10.254 255.255.255.0

华三 SecPath 命令基本相同（vlan、port link-type trunk、port trunk permit vlan、interface Vlan-interface10）。

2.6 路由模式 vs 透明模式

模式接口角色适用场景特点
路由模式接口配 IP，防火墙当"路由器+安检站"新建网络、有明确内外网划分需要配区域、策略、NAT，改动内网网段
透明模式接口不配 IP，像一根"带安检的网线"插入现有网络中（旁路/串联升级）无需改内网地址，二层透明转发

透明模式配置核心（华为）：

[Huawei] interface GigabitEthernet1/0/3
[Huawei-GigabitEthernet1/0/3] portswitch            # 切换为二层口
[Huawei-GigabitEthernet1/0/3] port link-type access
[Huawei-GigabitEthernet1/0/3] quit
[Huawei] firewall mode transparent                  # 全局切透明模式

华三 Comware 透明模式：[H3C] interface GigabitEthernet1/0/0 → port link-mode bridge（二层），策略配置同样依赖安全域。

三、安全区域（Security Zone）

3.1 什么是安全区域

安全区域是防火墙划分信任等级的逻辑分组：把接口分组，区域与区域之间默认"互不相通"，只有显式放行策略才允许互访。这是防火墙"默认拒绝一切、显式放行"的安全哲学的核心。

3.2 华为默认安全区域

区域名默认信任度典型用途
Local（本地）最高防火墙自身（管理流量、VPN 对端）
Trust（信任）高内网办公区、员工区
DMZ（隔离区）中对外提供服务的服务器区（Web/邮件）
Untrust（非信任）低互联网、外部不可信网络

3.3 区域优先级

华为 USG 按区域优先级做安全控制，从低优先级到高优先级的流量默认不允许（反向可配）。在配置策略时，源区域 + 目的区域是策略必须有的两个条件：

方向默认行为
Trust → Untrust默认拒绝（需策略放行）
Untrust → Trust默认拒绝（需策略放行）
Trust → DMZ默认拒绝（需策略放行）
Untrust → DMZ默认拒绝（需策略放行）

华三 SecPath 分区叫 security-zone，默认区域也是 trust/dmz/trustless/local，行为逻辑一致。

3.4 接口划入安全区域（核心命令）

[Huawei] firewall zone trust                 # 进入 trust 区域
[Huawei-zone-trust] add interface GigabitEthernet1/0/0   # 把内网口加进来
[Huawei-zone-trust] quit

[Huawei] firewall zone untrust
[Huawei-zone-untrust] add interface GigabitEthernet1/0/1
[Huawei-zone-untrust] quit

华为 V8 之后部分版本用 security-zone name trust，命令作用相同。 华三 Comware V7 的写法：[Huawei] security-zone name trust → [Huawei-security-zone-trust] import interface GigabitEthernet1/0/0（注意是 import 不是 add）。

查看区域划分：

[Huawei] display firewall-zone

四、安全策略基础

4.1 五元组（策略的最基本要素）

一条安全策略本质上是"五元组条件 → 动作"：

元素说明例子
源区域流量从哪里来Trust
目的区域流量去哪里Untrust
源地址谁发起192.168.1.0/24
目的地址访问谁0.0.0.0/0（任意）
服务（端口）访问什么服务TCP 80/443

4.2 规则匹配流程（防火墙怎么工作）

收到包 → 查五元组 → 从上往下逐条匹配安全策略
        ├─ 命中某条 → 按该条的动作放行/拒绝（命中即停，不再继续）
        └─ 全部不命中 → 丢包（默认拒绝，并记入会话表）

一句话：从上往下找第一条能匹配的规则，动作是 permit 就放、deny 就丢。所以策略顺序 = 安全权重，常用、宽泛的规则别放最上面，要放最下面。

4.3 创建第一条安全策略

目标：内网（Trust 区域 192.168.1.0/24）访问互联网（Untrust 区域任意地址任意端口）。

[Huawei] security-policy rule name internet_out   # 进入策略管理视图，新建名为 internet_out 的规则
[Huawei-policy-security-rule-internet_out] source-zone trust
[Huawei-policy-security-rule-internet_out] destination-zone untrust
[Huawei-policy-security-rule-internet_out] source-address 192.168.1.0 24
[Huawei-policy-security-rule-internet_out] destination-address any
[Huawei-policy-security-rule-internet_out] service any
[Huawei-policy-security-rule-internet_out] action permit
[Huawei-policy-security-rule-internet_out] quit
[Huawei-policy-security] quit

查看策略：

[Huawei] display security-policy rule all

4.4 动作：permit / deny

动作含义用途
action permit放行允许的业务
action deny拒绝拒绝的业务，如封锁危险端口

配置 deny 的例子：

[Huawei] security-policy
[Huawei-policy-security] rule name block_telnet_out
[Huawei-policy-security-rule-block_telnet_out] source-zone trust
[Huawei-policy-security-rule-block_telnet_out] destination-zone untrust
[Huawei-policy-security-rule-block_telnet_out] service tcp destination-port 23
[Huawei-policy-security-rule-block_telnet_out] action deny

注意：deny 策略必须放在 permit 策略前面，否则 permit any 先匹配了，deny 永远不生效。

4.5 默认行为

  • 华为 USG 出厂默认：所有跨区域流量全部拒绝
  • 同区域（Trust → Trust）默认允许
  • 访问防火墙自身（任意 → Local）默认拒绝（如需管理放行要显式加策略）

4.6 华三策略写法对比

华三 Comware V7 使用 object-policy + security-policy 两层，稍微绕一点：

[H3C] security-policy
[H3C-security-policy] rule 1 name trust-untrust
[H3C-security-policy-1] action pass
[H3C-security-policy-1] source-zone trust
[H3C-security-policy-1] destination-zone untrust
[H3C-security-policy-1] source-address 192.168.1.0 24
[H3C-security-policy-1] service tcp

（华三旧版用 zone-pair security + packet-filter，新版已统一为 security-policy，逻辑与华为一致。）

五、基本实验场景

5.1 场景一：内网访问互联网

拓扑（最典型的中小企业组网）：

  [PC1] 192.168.1.10 ──┐
  [PC2] 192.168.1.11 ──┤── 内网交换机 ── FW:GE1/0/0(192.168.1.254)
                       │                    FW:GE1/0/1(202.1.10.1) ── 运营商网关 ── Internet
  [服务器] 192.168.1.20┘

配置思路四步走：

  1. 接口配 IP（路由口）
  2. 区域划分（内网口→Trust，外网口→Untrust）
  3. NAT：内网访问外网用 Easy-IP（源地址伪装成出口 IP）
  4. 安全策略：Trust→Untrust 放行，回包由状态检测自动放行

完整命令（华为 USG）：

system-view
# 1. 接口 IP
interface GigabitEthernet1/0/0
 ip address 192.168.1.254 255.255.255.0
quit
interface GigabitEthernet1/0/1
 ip address 202.1.10.1 255.255.255.0
quit

# 2. 区域划分
firewall zone trust
 add interface GigabitEthernet1/0/0
quit
firewall zone untrust
 add interface GigabitEthernet1/0/1
quit

# 3. NAT 转换（源 NAT，Easy-IP）
nat-policy
 rule name nat_out
  source-zone trust
  destination-zone untrust
  action source-nat easy-ip
 quit
quit

# 4. 安全策略
security-policy
 rule name internet_out
  source-zone trust
  destination-zone untrust
  action permit
 quit
quit

# 5. 默认路由指向运营商
ip route-static 0.0.0.0 0 202.1.10.254

# 保存
save

验证三步：

[Huawei] display firewall session table          # 看有没有上网会话
[Huawei] display security-policy rule all        # 确认策略存在
[Huawei] ping 202.1.10.254                       # 防火墙自己能通外网网关

华三差异：nat-policy 语法为 nat outbound 2000（ACL 关联）或 nat easy-ip，策略名 rule name 相同。

5.2 场景二：内网访问 DMZ 服务器

拓扑：

  内网 PC 192.168.1.0/24 ── Trust ── FW ── DMZ 192.168.20.0/24
                                          └── Web 服务器 192.168.20.10

需求：内网只能访问 DMZ 的 Web 服务器 80 端口，其它全拒。

配置：

# DMZ 区域
firewall zone dmz
 add interface GigabitEthernet1/0/2
quit

interface GigabitEthernet1/0/2
 ip address 192.168.20.254 255.255.255.0
quit

# 策略：内网 → DMZ 只放 Web
security-policy
 rule name trust_to_dmz_web
  source-zone trust
  destination-zone dmz
  source-address 192.168.1.0 24
  destination-address 192.168.20.5 32
  service tcp destination-port 80
  action permit
 quit
quit

要点：目的地址精确到服务器 IP、端口精确到 80，其他流量默认落在"未命中 → 拒绝"，不用再写 deny。

5.3 常见错误与排查思路（初级版）

现象可能原因检查命令
内网不能上网区域未划分 / 未配 NAT / 策略没放行display firewall-zone、display security-policy rule all
能 ping 通外网 IP 但上不了网DNS 或 80/443 未放行检查 service 是否含 http/https
Web 访问不了防火墙Local 区域策略未放行管理端口策略里加 destination-zone local + service https
策略配置了不生效规则顺序问题 / 接口未加入对应区域看规则顺序，display firewall-zone 验证接口归属

初级排查五步法：接口 IP → 区域归属 → 策略是否命中 → NAT 是否生效 → 路由是否可达，逐层往下。
