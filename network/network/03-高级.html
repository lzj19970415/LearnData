网络基础·高级

本篇面向能独立完成中小型网络设计与排障的运维同学，覆盖 OSPF 进阶、BGP、VRRP 高可用、MPLS/VPN 概念、网络监控运维（SNMP/NTP/日志）、LLDP 与网管平台、企业三层架构设计，以及软考网络工程师考点提示。全程华为 VRP 命令（华三 Comware 差异处用括号标注）。

1. OSPF 进阶

1.1 多区域 OSPF

网络规模大时，单区域导致链路状态数据库（LSDB）庞大、SPF 计算频繁、收敛慢。多区域设计把网络按拓扑/功能分区，所有非骨干区域必须通过 Area 0（骨干）互联：

            Area 0 (骨干)
 R1 ─── R2 ─── R3 ─── R4
        |           |
     Area 1      Area 2

关键点：

概念说明
骨干区域Area 0，所有流量必经，相当于"高速公路主干道"
普通区域挂接在骨干区，区域内路由在内部汇总后通告
ABR区域边界路由器（同时连骨干与普通区域）
ASBR自治系统边界路由器（引入外部路由）

配置要点：每台路由器只在相连区域里 network 宣告直连网段；ABR 同时进入多个 area。

# R2（ABR：同时连 Area0 与 Area1）
[Huawei] ospf 1 router-id 2.2.2.2
[Huawei-ospf-1] area 0
[Huawei-ospf-1-area-0.0.0.0] network 10.0.1.0 0.0.0.255
[Huawei-ospf-1-area-0.0.0.0] quit
[Huawei-ospf-1] area 1
[Huawei-ospf-1-area-0.0.0.1] network 10.0.2.0 0.0.0.255
[Huawei-ospf-1-area-0.0.0.1] network 192.168.1.0 0.0.0.255

华三 Comware 命令完全一致（ospf 1 / area 1 / network ...）。

1.2 区域类型：Stub 区域

Stub 区域（末梢区域）：区域内没有 ASBR（不接受外部路由），区域内的路由器只需知道"出去走 ABR"，从而大幅缩减 LSDB。适用于只有一条出口的末端分支（如分公司、银行网点）。

在 ABR 上（Area 1 侧）宣告 Stub：

[Huawei-ospf-1] area 1
[Huawei-ospf-1-area-0.0.0.1] stub                    # 区域 1 为 Stub

区域内所有路由器都要配置 stub（同一区域内必须统一宣告）。效果：区域 1 内不再传播外部路由（类型 5 LSA），由 ABR 自动下发默认路由。

相关变种：Totally Stub（完全末梢，只保留默认路由，由 ABR 加 stub no-summary）。

1.3 LSA 类型速查（软考高频）

OSPF 路由表里的 O 类路由其实来自不同类型的 LSA，软考选择题和案例常考：

类型名称产生者说明
1Router LSA每台路由器本区域内的链路状态
2Network LSADR广播网的网段信息
3Summary LSAABR区域间路由摘要
4ASBR SummaryABR到 ASBR 的路由
5External LSAASBR外部（其他协议引入）路由

华为路由表中对应：O = 区内（1/2 类）、O IA = 区域间（3 类）、O E2/O E1 = 外部（5 类）。

[Huawei] display ospf lsdb                     # 查看链路状态数据库
[Huawei] display ospf lsdb summary             # 只看 3 类摘要
[Huawei] display ospf routing                  # 查看 OSPF 路由及类型

软考点提示：路由类型 O / O IA / O E2 的含义与范围优先级（区内 > 区域间 > 外部）必须会辨析。

1.4 DR/BDR 选举

在广播型网络（如以太网），OSPF 路由器之间若两两建立邻接，邻居关系会爆炸（n 台路由器 n(n-1)/2 条）。于是选举 DR（指定路由器）与 BDR（备份指定路由器），普通路由器（DRother）只和 DR/BDR 建邻接，DR 负责收集 LSA 后洪泛全网：

选举规则：接口 DR 优先级（priority）大者优先，默认 1；相同则 Router-ID 大者胜。

查看与修改：

[Huawei] display ospf peer                          # 查看邻居关系（含 DR/BDR 角色）
[Huawei] display ospf interface GigabitEthernet0/0/0
[Huawei-GigabitEthernet0/0/0] ospf dr-priority 100    # 修改接口 DR 优先级

实际运维注意：DR/BDR 是选举出来的，与 router-id 大小相关，并不可抢占（新路由器加入不会改变现有 DR）。想让特定设备成为 DR，在组网规划时就应调高优先级。

1.5 OSPF 路由汇总

汇总（聚合）把多条明细路由聚合成一条，减少 LSDB 与路由表规模、抑制路由震荡：

  • 区域间汇总：在 ABR 上做。
  • 外部路由汇总：在 ASBR 上做。
# 在 ABR 上把 Area 1 的多个网段汇总成 172.16.0.0/16 通告给 Area 0
[Huawei-ospf-1] area 1
[Huawei-ospf-1-area-0.0.0.1] abr-summary 172.16.0.0 255.255.0.0

华三对应 abr-summary 172.16.0.0 16（后面直接写前缀长度）。

1.6 下发默认路由

让内部网络"统统走出口"，在出口路由器（ASBR）上向 OSPF 域内下发默认路由：

[Huawei-ospf-1] default-route-advertise always
# 不写 always 时，只有本地已有默认路由（如静态 0.0.0.0/0）才下发

华三为 default-route-advertise 相同（无 always 参数，默认行为是只要路由表有默认路由就下发）。

验证：display ospf routing 应能看到 O E2 0.0.0.0/0 或 O E2 10.0.0.0/8 类路由。

2. BGP 基础

2.1 BGP 是什么

BGP（边界网关协议）是互联网/运营商之间交换路由的外部路由协议，基于 TCP 179 端口，专治"路由数量巨大、拓扑关系复杂"的场景。企业网涉及与运营商互联、专线对接时经常用到。AS（自治系统）：一个独立管理域，公网 AS 号由 ISP 分配，企业私网可用 64512~65535。

2.2 EBGP 与 IBGP

类型邻居关系典型场景
EBGP不同 AS 之间的邻居（直连物理口）企业与运营商、运营商之间
IBGP同一 AS 内部路由器AS 内传递外部路由

2.3 华为 BGP 配置示例

# R1（AS 65001）与 R2（AS 65002）直连，网段 10.0.0.0/24
# R1 配置
[R1] bgp 65001
[R1-bgp] peer 10.0.0.2 as-number 65002        # 指定邻居及其 AS
[R1-bgp] ipv4-family unicast
[R1-bgp-af-ipv4] peer 10.0.0.2 enable          # 激活邻居（BGP 后续演进必配）
[R1-bgp-af-ipv4] network 192.168.1.0 255.255.255.0    # 发布本地路由（network 是"宣告"，不是静态路由）
[R1-bgp-af-ipv4] quit

# R2 对称配置（AS 65002）
R2: peer 10.0.0.1 remote-as 65000
R2: network 192.168.2.0 255.255.255.0

关键：BGP 的 network 命令是"发布本地已存在的路由"（直连/静态/OSPF 学到的），且必须匹配。华三命令几乎一致（bgp 65001 / peer 10.0.0.1 as-number 65000 / network 192.168.2.0 24）。

2.4 查看 BGP 邻居

R1# display bgp peer                    # 邻居状态：Established 表示建立成功
R1# display bgp routing-table           # BGP 路由表
R1# display bgp peer 10.0.0.2           # 单个邻居详情

邻居建立状态机：Idle → Connect → OpenSent → OpenConfirm → Established。卡在 Idle 查：直连可达性、remote-as 是否正确、报文被 ACL 过滤；卡在 OpenConfirm 查：router-id 冲突、多协议不匹配。

2.5 BGP 路径属性与路由反射器（简述）

BGP 选路依赖路径属性（Path Attributes），核心几个：

属性作用
AS-PATH记录经过的 AS 序列，越长越不优（防环）
NEXT-HOP下一跳地址（IBGP 学到后仍保持 EBGP 的 next-hop，需注意）
LOCAL-PREF本地优先级，越高越优（AS 内出口选择）
MED多出口度量，越小越优（AS 间）

IBGP 水平分割：从 IBGP 邻居学到的路由不再通告给其他 IBGP 邻居，导致 IBGP 需要全互联。路由反射器（RR）解决该问题：RR 反射收到的 IBGP 路由给客户端，避免全网全互联。

[R2] bgp 65001
[R2-bgp] peer 10.0.1.1 reflect-client      # 把邻居指定为路由反射器客户端
[R2-bgp] display bgp routing-table peer 10.0.1.1  # 查看该邻居收到的路由

软考层面，能说出属性名字和选路顺序即可（WEIGHT > LOCAL_PREF > AS_PATH > MED > IGP cost...）。华三命令 peer 10.0.1.1 reflect-client 相同。

3. VRRP 高可用

3.1 虚拟网关原理

出口网关只有一台，挂了全网断网。VRRP（虚拟路由冗余协议）让多台路由器/三层交换机组成一个"虚拟路由器"（共享一个虚拟 IP 作为网关），正常情况下流量走 Master，Master 故障时 Backup 自动接管，切换对终端透明：

虚拟网关 IP：192.168.10.254
+-------+          +-------+
| SW1(Master) |←— 主转发     |  SW2(Backup) |
+-------+          +-------+
   └────────── 终端网关 = 192.168.10.254 ──────────┘

3.2 华为 VRRP 配置示例

需求：SW1 为主网关（优先级高），SW2 备份，虚拟网关 192.168.10.254，VLAN 10 内终端网关填 192.168.10.254。

# SW1（Master）
[Huawei] interface Vlanif 10
[Huawei-Vlanif10] ip address 192.168.10.1 255.255.255.0
[Huawei-Vlanif10] vrrp vrid 1 virtual-ip 192.168.10.254      # 创建 VRRP 组，虚拟 IP 即终端网关
[Huawei-Vlanif10] vrrp vrid 1 priority 120                 # 提高优先级到 120（默认 100）> Backup
[Huawei-Vlanif10] vrrp vrid 1 preempt-mode timer delay 5   # 抢占并延迟 5s（防频繁切换）
[Huawei-Vlanif10] quit

# SW2（Backup，默认优先级 100 即可）
[Huawei] interface Vlanif 10
[Huawei-Vlanif10] ip address 192.168.10.2 255.255.255.0
[Huawei-Vlanif10] vrrp vrid 1 virtual-ip 192.168.10.254
[Huawei-Vlanif10] quit

验证：

[Huawei] display vrrp                       # 查看 Master/Backup 状态、虚拟 IP
[Huawei] display vrrp brief
  • 正常：SW1 为 Master，SW2 为 Backup；
  • 拔掉 SW1 上联/停接口 → SW2 自动接管（约 3 秒），终端不掉线；
  • 终端网关地址必须写虚拟 IP（192.168.10.254），不是物理接口 IP。

华三 Comware 的 VRRP 命令相同（vrrp vrid 1 virtual-ip 192.168.10.254），差异点：华三 VRRP 属于三层，配合 interface Vlan-interface 10 使用。

3.3 VRRP 报文与认证（进阶了解）

VRRP 报文组播 224.0.0.18，可通过 vrrp vrid 1 authentication-mode simple cipher 开启简单认证，防止伪造。还可跟踪上行口/上行链路，使主设备下行链路断时自动降优先级交棒（配置较复杂，作为了解项）。

3.4 VRRP 双机负载分担（实战场景）

一台设备做主、另一台完全闲置浪费，生产中常用双组 VRRP 互相备份：VLAN10 以 SW1 为 Master、VLAN20 以 SW2 为 Master，两台设备都在转发流量：

# SW1：VLAN10 主（优先级 120），VLAN20 备（默认 100）
[SW1] interface Vlanif 10
[SW1-Vlanif10] vrrp vrid 1 virtual-ip 192.168.10.254
[SW1-Vlanif10] vrrp vrid 1 priority 120
[SW1-Vlanif10] quit
[SW1] interface Vlanif 20
[SW1-Vlanif20] vrrp vrid 2 virtual-ip 192.168.20.254
[SW1-Vlanif20] quit

# SW2：VLAN10 备，VLAN20 主
[SW2] interface Vlanif 10
[SW2-Vlanif10] vrrp vrid 1 virtual-ip 192.168.10.254
[SW2-Vlanif10] quit
[SW2] interface Vlanif 20
[SW2-Vlanif20] vrrp vrid 2 virtual-ip 192.168.20.254
[SW2-Vlanif20] vrrp vrid 2 priority 120

双机组网务必保证两台设备三层互联互通（中间跑 OSPF/静态路由），否则备用设备收到主设备的流量也无法转发。华三命令相同，接口名为 Vlan-interface。

4.1 MPLS 是什么

MPLS（多协议标签交换）：传统 IP 转发每跳查路由表（长前缀匹配，慢）；MPLS 在入口给报文打标签，中间路由器只按标签快速交换，支持流量工程（TE）和 VPN。

在 L3VPN 中，华为运营商（SP）网络用 MPLS 承载客户私有路由：

  • CE（客户边缘设备）：客户侧路由器/防火墙，直连 PE；
  • PE（运营商边缘设备）：接入客户，存放客户 VPN 路由；
  • P（骨干设备）：只做标签转发，不感知 VPN 客户。
CE1 (客户A总部) ── PE1 ──(MPLS 骨干: P)── PE2 ── CE2 (客户A分部)
               └───── VPN-A 专线逻辑连接 ─────┘

4.2 MPLS 标签转发流程（了解）

CE1 发送普通 IP 报文 → PE1（入站 PE）
  ① PE1 查 VRF 路由表，压入两层标签（内层 VPN 标签 + 外层 LSP 标签）
  ② P 设备只看外层标签转发（不查 IP 路由表，速度更快）
  ③ PE2 弹出外层标签，按内层 VPN 标签识别 VPN 实例，转发给 CE2
  ④ CE2 收到的是普通 IP 报文，全程不感知 MPLS

核心术语速记：

术语含义
LSP标签交换路径（标签经过的路径）
VRF / VPN-instance每 VPN 独立的路由表，实现路由隔离
RD路由区分符，解决不同客户同网段冲突
RT路由目标，决定 VPN 路由向谁发布（导入/导出）
MP-BGP扩展 BGP，在 PE 之间传递带标签的 VPN 路由

软考对 MPLS 主要考概念与 VPN 模型，不考复杂配置。能讲清 PE/P/CE 与"客户路由隔离"即可。

5. 网络监控与运维

5.1 SNMP 网络管理

SNMP（简单网络管理协议）是网管系统（如华为 eSight、Zabbix、Prometheus 类）从设备采集状态/告警的标准协议，版本 v1/v2c（明文 community）/v3（加密认证）。

华为设备开启 SNMP：

[Huawei] snmp-agent                          # 开启 SNMP 代理
[Huawei] snmp-agent sys-info version v2c     # 使用 v2c 版本
[Huawei] snmp-agent community read cipher public123    # 只读团体字（华三：snmp-agent community read public）
[Huawei] snmp-agent sys-info contact "it@telecom"
[Huawei] snmp-agent sys-info location "Room-101"
# 配置网管告警（Trap）上报：
[Huawei] snmp-agent trap enable
[Huawei] snmp-agent target-host trap address udp-domain 192.168.100.20 params securityname public v2c

华三差异：snmp-agent sys-info version v2c、snmp-agent community read public 语法一致；v3 配置 snmp-agent group v3 / snmp-agent usm-user v3。

验证：display snmp-agent、display snmp-agent community，或在网管端 snmpwalk 测试。

5.2 NTP 时间同步

日志、证书、计费都依赖时钟，必须统一。设备向 NTP 服务器对时：

[Huawei] ntp-service unicast-server 192.168.100.1          # 指定 NTP 服务器
[Huawei] ntp-service source-interface Vlanif 100           # 指定出接口（可选）
# 查看
[Huawei] display ntp status
[Huawei] display ntp service unicast-server

华三 Comware：ntp-service unicast-server 192.168.100.1，完全相同。确认状态：display ntp status 中 Clock Synchronized: yes。

5.3 日志管理（info-center）

把日志输出到 Console / 远程 syslog 服务器，方便集中审计：

[Huawei] info-center enable                       # 开启日志中心
[Huawei] info-center loghost 192.168.100.50       # 发往远程 syslog（华三：info-center loghost 192.168.100.50）
[Huawei] info-center timestamp log date            # 日志时间戳格式
[Huawei] display logbuffer                        # 查看本地日志
[Huawei] display alarm                            # 查看告警

实践：云平台告警/运维平台统一采集交换机日志，便于事件关联分析。华为设备日志级别：Emergency 0 ~ Debugging 7，常规采集 info（6）以上。

6. 华为网络管理工具

6.1 LLDP 链路层发现协议

LLDP 让交换机自动发现邻居设备及其能力（设备名、端口、VLAN 等），是网络可视化、自动拓扑的基础：

[Huawei] lldp enable                          # 全局开启（华三：lldp enable 相同）
[Huawei] interface GigabitEthernet0/0/1
[Huawei-GigabitEthernet0/0/1] lldp enable     # 接口可选
[Huawei] display lldp neighbor                # 查看发现的邻居
[Huawei] display lldp neighbor brief

华三为 lldp enable 与 display lldp neighbor brief（参数略有差异：display lldp neighbor brief 华三为 display lldp neighbor-information）。

6.2 华为网管平台简述

  • eSight：华为统一网管（NMS），支持拓扑、告警、性能、配置备份，面向企业网/数据中心；
  • iMaster NCE：下一代网络云化智能管理平台，面向 IP 网络（园区、广域、数据中心）；
  • eNSP 模拟器本身配合 Wireshark 可抓包分析协议细节。

运维场景：设备上线后接入 eSight 统一监控，设置告警策略（CPU 超 80%、端口 down、掉线）自动通知值班。

7. 企业网络综合设计与排障

7.1 三层架构（核心 / 汇聚 / 接入）

层次设备职责
核心层高端交换机/路由器高速转发、路由、策略；不做复杂过滤
汇聚层三层交换机路由汇总、ACL、QoS、网关（VLANIF）
接入层二层交换机接入终端、端口安全、VLAN 划分
核心层 SW1 ── SW2（双核心，VRRP/堆叠）
   │            │
汇聚层 S1 汇聚 S2（跑 OSPF/三层）
   │            │
接入层 A1 A2 A3（access 端口接终端）

设计原则：核心冗余（双机 VRRP）、汇聚收敛（OSPF 多区域/汇总）、接入隔离（每个终端限速+端口安全）。政务云/运营商 IDC 网络基本沿用"核心-汇聚-接入"模式。

7.2 常见网络故障排查方法

广播风暴：交换机 CPU 高、所有端口闪，单帧被反复转发成倍放大。排查：

  1. display mac-address 观察 MAC 反复跳变端口；
  2. display interface brief 找收发包异常激增口；
  3. 逐段拔线定位环路，用 shutdown 隔离；
  4. 根因多为成环 + 未启用 STP（生成树协议），或私接环路（网线回环）。

环路检测 loopback detection：华为交换机提供专门命令，自动检测接口环路并保护：

[Huawei] interface GigabitEthernet0/0/1
[Huawei-GigabitEthernet0/0/1] loopback-detect enable      # 开启环路检测
[Huawei-GigabitEthernet0/0/1] loopback-detect action shutdown   # 检测到环路自动 down 口
[Huawei-GigabitEthernet0/0/1] quit
[Huawei] display loopback-detect detection-result

华三 Comware：loopback-detection enable（全局）+ 接口 loopback-detection enable，动作 loopback-detection action shutdown，等效于华为的 loopback-detect。

7.3 STP 生成树协议基础（环路防护核心）

广播风暴的根因是二层环路 + 没有收敛机制。STP（生成树协议）自动把冗余链路中的一条设为阻塞（Block），逻辑上"剪"掉环路，链路故障时再快速恢复（重新计算）：

        SW1
       /    \
      /      \
    SW2 ----- SW3     ← 物理成环，STP 阻塞其中一条，形成树形无环逻辑拓扑

选举过程：

  1. 选根桥（Root Bridge）：交换机之间比较优先级（默认 32768）和 MAC，最小者当选；
  2. 每台非根交换机选根端口（Root Port，到根桥最短路径）；
  3. 每条链路选指定端口（Designated Port）；
  4. 其余端口进入 Blocking（阻塞）状态，不转发数据帧只收 BPDU。

端口状态：Disabled → Blocking → Listening → Learning → Forwarding（华为新版本为 Discarding/Learning/Forwarding）。

华为设备启用与调整：

[Huawei] stp enable                          # 全局开启 STP（默认开启）
[Huawei] stp mode stp                      # 模式：STP / RSTP（默认）/ MSTP
[Huawei] stp priority 4096                 # 指定根桥（数值越小越优先，4096 常做核心）
[Huawei] display stp                        # 查看 STP 状态、根桥、端口角色
[Huawei] display stp interface GigabitEthernet0/0/1   # 查看单端口角色与状态
[Huawei] stp disable                        # 全局关闭（不推荐，需确保无环）

华三 Comware：stp enable、stp mode rstp、stp priority 4096 一致；RSTP 收敛更快，生产推荐 RSTP/MSTP。

运维要点：

  • 永远别裸奔（无 STP + 成环 = 全网瘫痪）；
  • 交换机接终端的端口建议配 stp edged-port enable（边缘端口，接入后立即转发、不参与收敛，防止终端频繁插拔引发网络震荡）；
  • STP 收敛慢（默认 30~50 秒），RSTP/MSTP 收敛快（1~2 秒），核心网一般用 MSTP 多实例。

其他高频故障：

8.1 软考案例题演练（示例）

题目（改编）：某单位网络使用一台三层交换机 S1 连接两个 VLAN（VLAN 10 终端、VLAN 20 服务器），出口接路由器 R1 上互联网。要求：

  1. 在 S1 上创建 VLAN 10、20，端口 G0/0/1 划入 VLAN 10；
  2. 配置 VLANIF 实现两网段互通（VLAN10=192.168.10.0/24，VLAN20=192.168.20.0/24）；
  3. 在 S1 配置默认路由指向 R1 互联地址 10.0.0.2；
  4. 拒绝 192.168.10.0/24 访问 192.168.20.0/24 中的 1.1.1.1 端口 80。

参考答案要点：

[Huawei] vlan batch 10 20
[Huawei] interface GigabitEthernet0/0/1
[Huawei-GigabitEthernet0/0/1] port link-type access
[Huawei-GigabitEthernet0/0/1] port default vlan 10
[Huawei] interface Vlanif 10
[Huawei-Vlanif10] ip address 192.168.10.1 255.255.255.0
[Huawei] interface Vlanif 20
[Huawei-Vlanif20] ip address 192.168.20.1 255.255.255.0
[Huawei] ip route-static 0.0.0.0 0.0.0.0 10.0.0.2
[Huawei] acl number 3000
[Huawei-acl-adv-3000] rule 5 deny tcp source 192.168.10.0 0.0.0.255 destination 1.1.1.1 0 destination-port eq 80
[Huawei-acl-adv-3000] rule 10 permit ip
[Huawei-acl-adv-3000] quit
[Huawei] interface Vlanif 20
[Huawei-Vlanif20] traffic-filter inbound acl 3000

该类综合题覆盖"VLAN + VLANIF + 静态路由 + 高级 ACL"四件套，是软考下午案例的高概率组合。建议在 eNSP 上亲手搭建验证一遍。
