网络基础·初级

本篇面向电信运维岗位新手，从零讲清楚"网络是什么、IP 怎么算、交换机怎么配"，全程使用华为 eNSP 模拟器 + 华为 VRP 命令（华三 Comware 命令差异处用括号标注）。学完本篇，你应能独立搭一个小型二层网络并完成 VLAN 划分实验。

1. 计算机网络基础

1.1 什么是计算机网络

计算机网络是通过传输介质（网线、光纤、无线）把多台计算机和设备连接起来，按照统一协议进行通信和信息共享的系统。对运维而言，网络就是"让数据从 A 设备准确、快速、安全地到达 B 设备"的整套技术。

网络按规模可分为：

类型英文覆盖范围典型场景
局域网LAN一栋楼/一个园区办公室、机房
城域网MAN一个城市政务网、运营商城域
广域网WAN跨城市/跨国电信骨干网、互联网

1.2 OSI 七层模型

OSI（开放系统互连）参考模型把网络通信拆成 7 层，每层只管自己的事，层与层之间通过"接口"衔接。运维排障时按层定位问题，是最基本的方法论。

层次名称核心职责典型设备/协议
第 7 层应用层为用户提供应用服务HTTP、FTP、DNS、SMTP
第 6 层表示层数据编码、加密、压缩JPEG、SSL 加解密
第 5 层会话层建立/维护/终止会话NetBIOS
第 4 层传输层端到端传输、可靠控制TCP、UDP、端口
第 3 层网络层寻址与路由选择IP、ICMP、路由器
第 2 层数据链路层帧封装、MAC 寻址、差错检测交换机、以太网
第 1 层物理层比特流传输、电气特性网线、光模块、集线器

记忆口诀："物数网传会表应"，从上往下是"应表会传网数物"。

1.3 TCP/IP 四层模型

TCP/IP 是互联网实际使用的模型，把 OSI 七层合并为四层：

TCP/IP 层次对应 OSI 层代表协议
应用层5~7 层HTTP、DNS、DHCP、Telnet、SNMP
传输层4 层TCP、UDP
网际层3 层IP、ICMP、ARP
网络接口层1~2 层以太网、WIFI、PPP

1.4 传输层 TCP 与 UDP 的区别

TCP/IP 传输层只有两个主角，排障时首先要分清：

特性TCPUDP
连接面向连接（三次握手）无连接
可靠性可靠（确认+重传+排序）尽力而为
速度相对较慢快
典型应用Web、文件传输、邮件DNS 查询、视频直播、语音

1.5 常见协议与端口

端口用于区分同一台主机上的不同应用，范围 065535，知名端口（01023）归固定协议使用。这是运维必须背熟的表：

端口协议用途

23Telnet明文远程登录

记忆技巧：DNS 53、HTTP 80、HTTPS 443、SSH 22 四个必须脱口而出，其余查表即可。

1.6 数据封装与解封装过程

数据从终端发出到接收，每一层都会给上一层的数据"打包加头"（封装）；接收端再逐层拆包（解封装）：

层级数据单元名称封装内容
应用层数据 Data应用数据（如 HTTP 请求正文）
传输层段 SegmentTCP/UDP 头 + 源/目的端口
网络层包 PacketIP 头 + 源/目的 IP 地址
数据链路层帧 FrameMAC 头 + 源/目的 MAC 地址
物理层比特 Bit电信号/光信号

排障启示："ping 通但网页打不开"，说明网络层及以下正常，问题大概率在传输层/应用层（如防火墙拦截 HTTP 端口、代理配置错误）。"两层"逐层拆解的思想贯穿所有网络排障。

2. IP 地址

2.1 IPv4 地址的结构

IPv4 地址是 32 位二进制，通常写成点分十进制，例如 192.168.1.1。一个 IP 地址由两部分组成：

  • 网络位：标识所在的网络（相当于"小区"）；
  • 主机位：标识网络里的具体设备（相当于"门牌号"）。

子网掩码用来区分网络位和主机位：掩码中为 1 的位对应网络位，为 0 的对应主机位。例如 192.168.1.10/24，掩码为 255.255.255.0，前 24 位是网络位。

2.2 IPv4 地址分类

IPv4 按首字节范围分为 A~E 类：

类别首字节范围默认掩码用途
A 类1~126255.0.0.0（/8）大型网络
B 类128~191255.255.0.0（/16）中型网络
C 类192~223255.255.255.0（/24）小型网络
D 类224~239-组播
E 类240~255-研究保留

特殊地址：127.0.0.1 为回环地址（本机自测）；0.0.0.0 表示任意/默认；255.255.255.255 为有限广播。

2.3 私有地址

私有地址只能在局域网内使用，不公网路由。NAT（地址转换）把这些私有地址转换成公网 IP 才能上网：

类别私有网段掩码
A 类10.0.0.0~10.255.255.255/8
B 类172.16.0.0~172.31.255.255/12
C 类192.168.0.0~192.168.255.255/16

运营商常见的政企内网、云资源池（天翼云、云轴私有云）大量使用 10.x.x.x 和 172.16.x.x 网段，学会用 ipconfig（Windows）/ ip addr（Linux）快速判断自己所在的网段与掩码。

2.4 子网掩码与 CIDR

CIDR（无类域间路由）用 /数字 表示掩码长度，如 192.168.1.0/24 等价于 255.255.255.0。常见对照表：

掩码前缀主机数（可用）
255.0.0.0/82^24 - 2 = 16777214
255.255.0.0/162^16 - 2 = 65534
255.255.255.0/242^8 - 2 = 254
255.255.255.128/252^7 - 2 = 126
255.255.255.192/262^6 - 2 = 62
255.255.255.224/272^5 - 2 = 30
255.255.255.248/292^3 - 2 = 6

每个子网要扣掉 2 个地址：网络地址（主机位全 0）和广播地址（主机位全 1）。

2.5 子网划分计算（例题）

例题 1：把 192.168.1.0/24 划分成 4 个等长子网，求各子网的网络地址、可用主机范围和掩码。

计算步骤：

  1. 需要 4 个子网，2^n ≥ 4，n = 2，即向主机位借 2 位；
  2. 新掩码 = 24 + 2 = 26 位，即 255.255.255.192；
  3. 每个子网的主机数 = 2^(8-2) - 2 = 62 台；
  4. 子网步长 = 256 - 192 = 64。
子网网络地址可用主机范围广播地址
1192.168.1.0/26192.168.1.1~192.168.1.62192.168.1.63
2192.168.1.64/26192.168.1.65~192.168.1.126192.168.1.127
3192.168.1.128/26192.168.1.129~192.168.1.190192.168.1.191
4192.168.1.192/26192.168.1.193~192.168.1.254192.168.1.255

例题 2：公司要容纳 100 台主机，申请到 172.16.1.0/24，如何规划？

每子网需主机位 2^n - 2 ≥ 100，n = 7，即 128 个地址为一个子网，掩码 /25：

  • 子网 A：172.16.1.0/25（主机 172.16.1.1~172.16.1.126）
  • 子网 B：172.16.1.128/25（主机 172.16.1.129~172.16.1.254）

2.6 网关的作用

网关（Gateway）是连接不同网络的那道"门"，通常是路由器的接口或三层交换机的 VLANIF 地址。主机访问非本地网段的地址时，数据包一律发给网关，由网关负责路由转发。

PC 判断逻辑：
目标 IP 与本地 IP 在同一个网段 → 直接 ARP 解析目标 MAC 发送；
目标 IP 不在同一网段 → 交给网关（查 ARP 表，得到网关 MAC 再发）。

运维经验："能上网但打不开某个内网"先看网关；"同一网段都不通"先看交换机和网线；"网关都 ping 不通"先看本机网卡和 IP 配置。

2.7 ARP 协议与 ICMP（ping 的原理）

ARP（地址解析协议）：已知 IP 查 MAC。主机要发包给同网段设备时，先发 ARP 广播"谁是 192.168.1.1？请告诉我 MAC"，目标收到后单播回复 ARP 应答，双方把对应关系写进 ARP 表。

<Huawei> display arp        # 查看 ARP 表（IP 与 MAC 的对应）

ICMP（互联网控制报文协议）：ping 和 tracert 基于它工作。ping 发送 Echo Request，目标回 Echo Reply，通过回复时间/丢包即可判断链路质量。

ping 现象常见原因
超时无回应目标关机、路由不通、防火墙拦截
请求超时但 IP 通ICMP 被禁用、负载高丢包
时延高/抖动大链路拥塞、光衰、WiFi 干扰

2.8 一台 PC 的完整上网过程（综合理解）

  1. PC 配置 IP/掩码/网关（DHCP 自动获取或手工）；
  2. 访问外网域名 → 先查 DNS（53）解析出公网 IP；
  3. 发现目的 IP 不在本地网段 → 数据包交给网关（ARP 解析网关 MAC）；
  4. 网关（路由器）查路由表转发，经运营商 NAT 转换成公网 IP；
  5. 对端回包按同样路径返回。

任何一个环节断了，现象各不相同——这就是排障要从 IP、网关、DNS 逐层排查的原因。

3. 华为 eNSP 模拟器入门

3.1 eNSP 是什么

eNSP（Enterprise Network Simulation Platform，华为网络仿真平台）是华为官方免费的网络模拟器，可在 PC 上模拟路由器、交换机、防火墙、无线等设备，用于学习与实验，无需真机。它对标华三的 HCL（H3C Cloud Lab）。

3.2 安装要点

  1. 先装 WinPcap 抓包软件（部分版本用 Npcap），否则接口无法工作；
  2. 安装 eNSP 主程序；
  3. 建议在 Windows 10/11 上以管理员身份运行；
  4. 若设备启动报错，检查 Windows 虚拟化（Virtualization）是否开启；
  5. 装好后再在 eNSP 中导入 VRP 版本镜像（不同版本设备型号对应不同 VRP 版本）。

常见型号：AR2220/AR201 路由器、S5700/S3700 交换机、CE12800 高端交换机、AC6605 无线控制器。

3.3 搭建拓扑

以"两台 PC 接一台交换机"为例：

  1. 打开 eNSP，新建工程；
  2. 左侧设备面板拖入 S5700 交换机 1 台、PC 主机 2 台；
  3. 点击工具栏"连线"→ 选"Copper"（铜缆），依次点击交换机端口 GigabitEthernet0/0/1 和 PC 的 Ethernet0/0/1 相连；
  4. 给两台 PC 配置 IP：双击 PC → 切换到"IPv4 配置"→ IP 填 192.168.1.10 / 192.168.1.20，掩码 255.255.255.0，网关可不填（同网段直连）。

3.4 启动设备

  1. 选中交换机图标，点击工具栏启动按钮（▶），设备图标从灰色变为亮色；
  2. 右键设备 → 选择"启动"等效；
  3. 设备启动需要 10~30 秒，底部出现设备软件版本信息即启动完成。

注意：PC 端（终端）在 eNSP 中作为"终端/主机"，启动后可直接打开命令行 ping 对端，验证链路。

3.5 Console 连接

模拟器中"连 Console"就是双击设备的图标打开命令行窗口（等价于真实设备插 console 线 + 超级终端）。真实设备上连接方法是：

  1. 使用 USB-to-RS232 转换线，Console 口连接 PC 的串口；
  2. 使用终端软件（SecureCRT / PuTTY / Xshell）新建会话；
  3. 协议选 Serial，波特率 9600，数据位 8、停止位 1、无校验、无流控；
  4. 连接后敲回车即可进入华为 VRP 命令行。

企业运维连防火墙/交换机常用 SSH（22）远程，Console 是"救命通道"（忘记 SSH 密码时可用 Console 恢复）。

3.6 抓包验证与工程管理

  1. eNSP 中在连线上右键选择"开始抓包"，会自动拉起 Wireshark 抓取该链路上的帧——强烈建议亲手抓一次 ARP/DNS/ICMP 报文，对比"1.6 数据封装"一节的字段；
  2. 工程保存：菜单"文件 → 另存为工程"生成 .ensp 文件，设备配置可右键设备导出为文本备份；
  3. 注意：eNSP 的配置与真机配置文件格式一致，可直接复制命令到真机（但抓包/模拟功能不可替代真机）。

VRP（Versatile Routing Platform）是华为统一的网络操作系统，华为设备所有功能都通过 VRP 命令行配置。华三 Comware 的命令体系与 VRP 高度相似，学会华为，华三基本可秒上手。

display 系列是运维最重要的查看命令，类似"查看器"，只读不改配置：

<Huawei> save                          # 保存配置（提示时输入 Y）

运维习惯：改任何关键配置前先 save 备份，display current-configuration | include xxxx 可过滤查看关键段。

5. 以太网与交换机

5.1 以太网帧与 MAC 地址

以太网帧是数据链路层的传输单元，核心字段：目的 MAC、源 MAC、类型、数据、校验（CRC）。

MAC 地址（物理地址）由 48 位（6 字节）十六进制组成，如 00-E0-FC-12-34-56，前三段是厂商 OUI（可查询网卡厂商），后三段是设备唯一标识。MAC 只在本地网段有效，跨网段靠 IP + 路由器。

5.2 交换机转发原理（MAC 表）

交换机是二层设备，工作在数据链路层，核心是维护一张 MAC 地址表（MAC 与端口的对应关系）：

MAC 地址端口类型
00-E0-4C-68-01-01GigabitEthernet0/0/1动态学习
00-E0-4C-68-02-02GigabitEthernet0/0/2动态学习

转发流程：

  1. 收到数据帧，记录源 MAC + 入端口（自学习）；
  2. 查找目的 MAC 的表项：
    • 命中 → 从对应端口转发（单播）；
    • 未命中 → 向所有其他端口广播（泛洪），等待学习；
  3. 目的 MAC 是广播帧（FF-FF-FF-FF-FF-FF）→ 泛洪到所有端口；
  4. 老化机制：动态 MAC 表项超时（默认 300 秒）自动删除。
<Huawei> display mac-address        # 查看当前 MAC 表
<Huawei> display mac-address aging-time     # 查看老化时间

5.3 VLAN 概念与作用

VLAN（Virtual LAN，虚拟局域网）把一台物理交换机在逻辑上分割成多个独立的广播域。

问题引出：默认所有端口在 VLAN 1，任何广播（ARP、DHCP）都会传遍全交换机。广播过多 → 广播风暴、带宽浪费、安全隐患。

VLAN 的作用：

作用说明
隔离广播域每个 VLAN 的广播只在本 VLAN 内转发
提升安全不同部门/网段互相隔离，互不可见
简化管理按部门/业务划分，便于策略控制

VLAN 编号范围：1~4094（1 是默认 VLAN，不可删除）。常用方式：10 办公、20 财务、30 服务器、100 管理。

华三创建 VLAN 用 vlan batch 10 20，华为等价为 vlan batch 10 20，语法一致。

5.4 物理介质与华为接口命名

介质类型特点华为接口命名
双绞线超五类/六类100m 以内、RJ45Ethernet（百兆）、GigabitEthernet（千兆）
光纤单模/多模单模 10km+、多模几百米光口板卡 + 光模块
无线WiFi灵活、受遮挡影响大无线控制器 + AP

eNSP 中连线时选 Copper（铜缆）接以太口，跨设备光连接可选 Fiber（光纤）。接口命名中 GigabitEthernet0/0/1 表示：第 1 槽位、第 0 子卡、第 1 端口。

6. 交换机基础配置实验（华为 eNSP）

6.1 实验拓扑与需求

PC1 (192.168.10.10/24) ---  SW1 (S5700)  --- PC2 (192.168.10.20/24)
PC3 (192.168.20.10/24) ---                --- PC4 (192.168.20.20/24)

需求：PC1/PC2 属于 VLAN 10（办公），PC3/PC4 属于 VLAN 20（财务），两部门互相隔离。

6.2 创建 VLAN

<Huawei> system-view
[Huawei] sysname SW1                        # 改名
[SW1] vlan batch 10 20                      # 批量创建 VLAN 10、20
[SW1] display vlan                          # 确认 VLAN 已创建

6.3 接口配置 access 类型并划分 VLAN

交换机连接 PC 的接口一般是 access 端口（只承载一个 VLAN）：

[SW1] interface GigabitEthernet0/0/1
[SW1-GigabitEthernet0/0/1] port link-type access        # 端口类型改为 access
[SW1-GigabitEthernet0/0/1] port default vlan 10         # 划分到 VLAN 10（华三：port access vlan 10）
[SW1-GigabitEthernet0/0/1] quit

[SW1] interface GigabitEthernet0/0/2
[SW1-GigabitEthernet0/0/2] port link-type access
[SW1-GigabitEthernet0/0/2] port default vlan 10
[SW1-GigabitEthernet0/0/2] quit

[SW1] interface GigabitEthernet0/0/3
[SW1-GigabitEthernet0/0/3] port link-type access
[SW1-GigabitEthernet0/0/3] port default vlan 20
[SW1-GigabitEthernet0/0/3] quit

[SW1] interface GigabitEthernet0/0/4
[SW1-GigabitEthernet0/0/4] port link-type access
[SW1-GigabitEthernet0/0/4] port default vlan 20
[SW1-GigabitEthernet0/0/4] quit

华三 Comware 差异：华三同样 port link-type access，进 VLAN 命令是 port access vlan 10，而不是华为的 port default vlan 10。两条命令的本质都是"把该端口划分到 VLAN"。

6.4 验证实验结果

[SW1] display vlan
[SW1] display port vlan                      # 查看各端口所属 VLAN
[SW1] display mac-address

PC1 ping PC2 → 通（同一 VLAN 10）； PC1 ping PC3 → 不通（不同 VLAN，二层隔离）。 不同 VLAN 默认不能互访，这是二层隔离的本质，也是后续"VLAN 间路由"要解决的问题（见中级篇）。

6.5 常用接口类型速查

端口类型用途华为配置
access接 PC/服务器，只属于一个 VLANport link-type access + port default vlan 10
trunk交换机之间级联，透传多个 VLAN中级篇
hybrid华为特色，可指定多 VLAN 且可打标进阶了解

交换机接口模式下还有 shutdown / undo shutdown 关闭和启用端口，description to-server 给端口起名，是运维日常最常用命令。
