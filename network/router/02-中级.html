路由器·中级

网络设备网络路由器华为约 3089 字大约 10 分钟

本笔记为"路由器"系列第 2 篇（共 3 篇），面向已掌握静态路由的进阶学习者。华为 VRP 命令为主，华三 Comware 差异处用（括号）标注。

路由器·中级

1. 动态路由协议对比

1.1 RIP / OSPF / BGP 核心对比

协议算法度量适用范围优缺点
RIP距离矢量（贝尔曼-福特）跳数小型网络（≤15 跳）配置简单；收敛慢，有环路问题
OSPF链路状态（SPF 算法）Cost（10^8/带宽）中大型企业网收敛快、无环路、支持分层
BGP路径矢量多种属性（AS 路径等）跨 AS 的运营商/大型企业策略丰富、可靠；配置复杂

选择建议：内网少则静态路由；小型动态网络用 RIP（现在基本淘汰）；中型企业用 OSPF；与运营商互联、多出口选路用 BGP。

1.2 华为启用配置对比

① RIP（示例 R1 与 R2 两跳内互通告）：

[R1]rip 1
[R1-rip-1]network 10.0.0.0          # 只宣告主类网段！华为 RIP 用主类网络号
[R1-rip-1]version 2                    # 用 RIPv2（V1 不支持 VLSM/认证）

② OSPF：

[R1]ospf 1 router-id 1.1.1.1
[R1-ospf-1]area 0
[R1-ospf-1-area-0.0.0.0]network 10.0.0.0 0.0.0.255

③ BGP（与邻居 AS 建立）：

[R1]bgp 65001
[R1-bgp]peer 10.0.1.2 as-number 65002

华三 Comware 差异：RIP 启用命令为 [R1]rip 1 + network 10.0.0.0（同为有类）；OSPF 启用命令相同 ospf 1 router-id 1.1.1.1；BGP 相同 bgp 65001。

2. OSPF 单区域配置详解

2.1 基本概念

  • 进程号（Process-ID）：本设备上可以运行多个 OSPF 进程，进程号只在本设备有效。
  • 区域（Area）：OSPF 分层的单位，单区域实验全部在 Area 0（骨干区域）。
  • Router-ID：路由器在 OSPF 中的身份标识，建议手动指定（否则自动取 LoopBack 最大 IP / 接口最大 IP）。

2.2 单区域配置（eNSP 拓扑）

拓扑：R1(10.0.12.1) -- R2(10.0.12.2 / 10.0.23.2) -- R3(10.0.23.3 / 10.0.34.3)，全部 Area 0。

R1：

[Huawei]sysname R1
[R1]interface GigabitEthernet0/0/0
[R1-GigabitEthernet0/0/0]ip address 10.0.12.1 255.255.255.0
[R1-GigabitEthernet0/0/0]quit
[R1]interface LoopBack0
[R1-LoopBack0]ip address 1.1.1.1 255.255.255.255
[R1-LoopBack0]quit
[R1]ospf 1 router-id 1.1.1.1
[R1-ospf-1]area 0
[R1-ospf-1-area-0.0.0.0]network 10.0.12.0 0.0.0.255
[R1-ospf-1-area-0.0.0.0]network 1.1.1.1 0.0.0.0        # 通告 LoopBack0

R2：

[R2]ospf 1 router-id 2.2.2.2
[R2-ospf-1]area 0
[R2-ospf-1-area-0.0.0.0]network 10.0.12.0 0.0.0.255
[R2-ospf-1-area-0.0.0.0]network 10.0.23.0 0.0.0.255

R3：

[R3]ospf 1 router-id 3.3.3.3
[R3-ospf-1]area 0
[R3-ospf-1-area-0.0.0.0]network 10.0.23.0 0.0.0.255
[R3-ospf-1-area-0.0.0.0]network 10.0.34.0 0.0.0.255

通配符反掩码：0.0.0.255 表示掩码为 255.255.255.0；精确主机用 0.0.0.0；网段 10.0.0.0/16 用 0.0.255.255。华为命令中反掩码和地址之间没有逗号，华三 Comware 同样如此（区别于 Cisco 的 network 10.0.12.0 0.0.0.255 area 0）。

2.3 验证命令

[R1]display ospf peer                    # 邻居状态（Full/2Way/Init 等）
[R1]display ospf interface               # OSPF 使能接口、Cost、DR/BDR
[R1]display ospf routing                 # OSPF 路由表
[R1]display ip routing-table protocol ospf   # 只看 OSPF 路由
[R1]display ospf error                   # OSPF 邻居失败排查常用

2.4 DR/BDR 选举

  • 广播多路访问链路（以太网）上，所有路由器与 DR（指定路由器）、BDR（备份指定路由器） 建立 FULL 邻接，其余互相为 Two-Way，减少 LSA 洪泛。
  • 选举规则：先比接口优先级（默认 1，ospf dr-priority 可改），数值大者优先；相同则比 Router-ID，大者优先。
  • 优先级为 0 表示不参与选举。DR/BDR 不抢占（DR 挂了 BDR 顶上）。
[R1]interface GigabitEthernet0/0/0
[R1-GigabitEthernet0/0/0]ospf dr-priority 10    # 设置 DR 优先级

2.5 OSPF 邻居状态机（排障必背）

OSPF 邻居状态依次经历：

Down → Init → 2-Way → ExStart → Exchange → Loading → Full
  • 2-Way：双向邻居关系已建立（广播网上普通路由器之间到此为止，仅 DR/BDR 才继续）。
  • Full：邻接关系建立完成，LSDB 完全同步，可正常转发。
[R1]display ospf peer          # 状态为 Full 才正常
[R1]display ospf peer brief

邻居停在 Init / 2-Way 排障：① 两端区域号是否一致；② Router-ID 是否冲突；③ 反掩码是否宣告了互联网段；④ 接口是否配了 silent-interface；⑤ 是不是认证不匹配（华为/华三认证配置需一致）；⑥ 华为默认 OSPF 报文认证为无，华三也默认无，若配了 authentication-mode md5 则两端口都要配且 key-id/密码一致。

2.6 OSPF Cost 与接口开销调整

[R1-GigabitEthernet0/0/0]ospf cost 10        # 手动调整该接口 OSPF Cost
[R1]ospf 1
[R1-ospf-1]bandwidth-reference 10000         # 修改参考带宽（默认 100Mbps）
  • Cost 默认 = 10^8 / 接口带宽。10GE 参考带宽不够时 Cost 会全部取整为 1，导致选路不准，大带宽环境需调大参考带宽。

3. ACL 访问控制列表

3.1 基本 ACL 与高级 ACL 区别

类型编号范围匹配条件典型用途
基本 ACL2000-2999仅源 IP 地址按来源过滤、NAT 指定转换
高级 ACL3000-3999源/目的 IP、协议、端口、DSCP 等精细化访问控制

华三编号范围相同（基本 2000-2999，高级 3000-3999）。

3.2 基本 ACL 示例

需求：拒绝网段 192.168.10.0/24 的 PC 访问内网服务器 192.168.20.0/24（在 R1 的入接口方向过滤）：

[R1] acl 2000
[R1-acl-basic-2000] rule 5 deny source 192.168.10.0 0.0.0.255
[R1-acl-basic-2000] rule 10 permit source any
[R1-acl-basic-2000] quit
[R1] interface GigabitEthernet0/0/0
[R1-GigabitEthernet0/0/0] traffic-filter inbound acl 2000

华为命令：traffic-filter inbound acl 2000；华三 Comware 用 packet-filter 2000 inbound。

3.3 高级 ACL 示例

需求：只允许 PC 192.168.10.10 访问服务器 192.168.20.1 的 HTTP(80) 端口，其余 TCP 全部禁止（在入接口应用）：

[R1]acl 3000
[R1-acl-adv-3000]rule 5 permit tcp source 192.168.10.10 0 destination 192.168.20.1 0 destination-port eq 80
[R1-acl-adv-3000]rule 10 deny ip
[R1-acl-adv-3000]quit
[R1]interface GigabitEthernet0/0/0
[R1-GigabitEthernet0/0/0]traffic-filter inbound acl 3000
  • 匹配顺序：默认按 rule 编号从小到大匹配，匹配即停止（ID 5 先于 10）。
  • ACL 默认末尾隐式拒绝 all，因此要"拒绝什么"时记得在最后加 rule permit ip 放行其他流量。
  • 方向：inbound（进入接口方向）/ outbound（从接口出去），要选对。

3.4 ACL 配置技巧

① 规则编号与自动编号：不写编号时华为自动以 5 递增（5、10、15…）；rule 5 与 rule 10 之间留空隙便于以后插入。

[R1-acl-adv-2000]rule 6 permit source 192.168.11.0 0.0.0.255   # 任何编号插入，无需重排

② 时间段（time-range）：上班时间才生效的策略：

[R1]time-range work 8:00 to 18:00 working-day
[R1]acl 3001
[R1-acl-adv-3001]rule 5 deny tcp source 192.168.10.0 0.0.0.255 destination 192.168.20.0 0.0.0.255 destination-port eq www time-range work

③ 华为 NAT 也可以引用 ACL（见第 4 章），所以基本 ACL 常用作 NAT 的"放行清单"，不要再往里面加拒绝规则。

④ 查看与清除：

[R1]display acl 3000            # 查看 ACL 命中计数（判断规则是否生效）
[R1]display traffic-filter applied-record    # 查看 ACL 应用到哪些接口

4. NAT 地址转换

4.1 概念

NAT（网络地址转换）：把私网地址映射为公网地址。企业内网用私网地址（10.x/172.16-31.x/192.168.x），访问互联网必须经出口路由器 NAT 转换。

场景：内网 192.168.10.0/24 通过公网接口 GE0/0/1（运营商分配 100.1.1.1）上网。

4.2 静态 NAT（一对一）

[R1] interface GigabitEthernet0/0/1
[R1-GigabitEthernet0/0/1] nat static global 100.1.1.10 inside 192.168.10.10
# 华三: nat static outbound 192.168.10.10 100.1.1.10（旧版命令 nat server 是端口映射）

4.3 动态 NAT（一对多地址池）

[R1] nat address-group 1 100.1.1.20 100.1.1.30
[R1] acl 2000
[R1-acl-basic-2000] rule 5 permit source 192.168.10.0 0.0.0.255
[R1-acl-basic-2000] quit
[R1] interface GigabitEthernet0/0/1
[R1-GigabitEthernet0/0/1] nat outbound 2000 address-group 1

4.4 NAPT（端口复用，最常用）easy-ip 写法

[R1] acl 2000
[R1-acl-basic-2000] rule 5 permit source 192.168.10.0 0.0.0.255
[R1-acl-basic-2000] quit
[R1] interface GigabitEthernet0/0/1
[R1-GigabitEthernet0/0/1] ip address 100.1.1.1 255.255.255.0
[R1-GigabitEthernet0/0/1] nat outbound 2000         # 直接复用公网口 IP（easy-ip）

easy-ip：不建地址池，直接使用出接口 IP，靠端口号区分内部多台主机。华三 nat outbound 2000 命令相同，也可 nat outbound 2000 address-group 1。

4.5 端口映射（内网服务器对外发布）

[R1] interface GigabitEthernet0/0/1
[R1-GigabitEthernet0/0/1] nat server protocol tcp global 100.1.1.1 80 inside 192.168.10.10 80
# 华三：nat server protocol tcp global 100.1.1.1 80 inside 192.168.10.10 80

4.6 查看 NAT 会话

[R1]display nat session all          # 查看所有 NAT 表项（源/目的/转换前后）
[R1]display nat outbound             # 查看出向 NAT 配置
[R1]display nat address-group        # 查看地址池

排查 NAT 不生效：① 先确认能上网（ping 公网）；② 查看 ACL 是否放行了内网段；③ display nat session 看是否建立会话；④ 检查接口方向（一般在出接口配置 outbound）。

5. DHCP 服务

5.1 路由器做 DHCP Server

需求：R1 为 192.168.10.0/24 网段终端分配 IP，网关 192.168.10.254。

[R1] dhcp enable                       # 全局开启 DHCP 服务（华为）
[R1] ip pool vlan10                    # 创建地址池 vlan10
[R1-ip-pool-vlan10] network 192.168.10.0 mask 255.255.255.0
[R1-ip-pool-vlan10] gateway-list 192.168.10.254
[R1-ip-pool-vlan10] dns-list 114.114.114.114 8.8.8.8
[R1-ip-pool-vlan10] lease day 3 hour 0 minute 0   # 租期3天，可选
[R1-ip-pool-vlan10] excluded-ip-address 192.168.10.1 192.168.10.50  # 排除保留地址
[R1-ip-pool-vlan10] quit
[R1] interface GigabitEthernet0/0/0
[R1-GigabitEthernet0/0/0] ip address 192.168.10.254 255.255.255.0
[R1-GigabitEthernet0/0/0] dhcp select global        # 接口启用全局地址池

华三 Comware：dhcp enable（全局开启），接口下 dhcp select global（或 dhcp select interface 用接口子网做池）。排除地址命令同为 excluded-ip-address。

5.2 DHCP 中继

当 DHCP Server 与客户端不在同一网段时，路由器做中继转发 DHCP 报文：

[R2] interface GigabitEthernet0/0/0
[R2-GigabitEthernet0/0/0] ip address 192.168.10.254 255.255.255.0
[R2-GigabitEthernet0/0/0] dhcp select relay
[R2-GigabitEthernet0/0/0] dhcp relay server-address 10.0.0.5   # DHCP 服务器地址

5.3 验证

[R1]display ip pool                      # 查看所有地址池及分配情况
[R1]display ip pool name vlan10           # 查看指定地址池
[R1]display dhcp server statistics        # DHCP 报文统计（排查分配异常用）

注意：若在"二层交换机"上想让接入终端通过路由器获取 IP，交换机无需配 DHCP，只需把接口划入对应 VLAN 即可。

6. 链路聚合、浮动静态路由与路由漂移

6.1 链路聚合（Eth-Trunk）

在两台路由器（或路由器到交换机）之间捆绑多条物理链路，提高带宽与可靠性：

R1 侧：

[R1] interface Eth-Trunk1
[R1-Eth-Trunk1] mode manual load-balance        # 手动负载分担（另一侧必须一致）
[R1-Eth-Trunk1] ip address 10.0.100.1 255.255.255.0
[R1-Eth-Trunk1] quit
[R1] interface GigabitEthernet0/0/0
[R1-GigabitEthernet0/0/0] eth-trunk 1
[R1-GigabitEthernet0/0/0] quit
[R1] interface GigabitEthernet0/0/1
[R1-GigabitEthernet0/0/1] eth-trunk 1

R2 侧同样配置（接口加入 Eth-Trunk 2，IP 10.0.100.2）。

[R1] display eth-trunk 1        # 查看成员接口状态（Up/Down）

华三 Comware：接口命名 interface Bridge-Aggregation 1，成员接口命令 port link-aggregation group 1；查看 display link-aggregation verbose。

6.2 静态路由负载均衡（等价路由）

两条链路带宽相同，可配置两条等价静态路由实现负载分担：

[R1] ip route-static 192.168.20.0 255.255.255.0 10.0.100.2
[R1] ip route-static 192.168.20.0 255.255.255.0 10.0.200.2

display ip routing-table 中会同时出现两条（Equal Cost）。

6.3 浮动静态路由（主备切换）

需求：默认走专线（10.0.100.2），专线断了自动切到备份链路（10.0.200.2）：

[R1] ip route-static 0.0.0.0 0.0.0.0 10.0.100.2 preference 60      # 主
[R1] ip route-static 0.0.0.0 0.0.0.0 10.0.200.2 preference 90      # 备（数值大，优先级低）
  • 正常情况下路由表只有 10.0.100.2 那条；主链路 down 后，备份路由生效，自动切换。
  • 静态路由本身没有"心跳探测"，依赖接口 Up/Down 状态。若主链路接口仍 Up（如中间设备故障）则不会切换，此时可配合 NQA（网络质量分析） 检测并联动静态路由：
[R1] nqa test-instance admin trunk-test
[R1-nqa-admin-trunk-test] test-type icmp
[R1-nqa-admin-trunk-test] destination-address ipv4 10.0.1.1
[R1-nqa-admin-trunk-test] probe-count 3
[R1-nqa-admin-trunk-test] frequency 10
[R1-nqa-admin-trunk-test] quit
[R1] ip route-static 0.0.0.0 0.0.0.0 10.0.100.2 track nqa admin trunk-test

华三对应：ip route-static 0.0.0.0 0 10.0.100.2 track 1 + nqa 配置（nqa entry admin test）。不同厂商细节有差异，核心思想一致：探测失败时撤销主路由，让备份路由浮起来。
