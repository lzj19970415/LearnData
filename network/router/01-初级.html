本笔记为"路由器"系列第 1 篇（共 3 篇），面向零基础入门。掌握后建议继续学习《路由器·中级》。 华为 VRP 命令为主，华三 Comware 差异处用（括号）标注。

路由器·初级

1. 路由器是什么

1.1 路由与交换的区别

  • 交换机（二层）：工作在 OSI 数据链路层（第 2 层），依据 MAC 地址表 转发数据帧，只能连接同一网段（同一广播域）内的设备。
  • 路由器（三层）：工作在网络层（第 3 层），依据 路由表 转发 IP 报文，可以连接不同网段，隔离广播域，是"不同网络之间的邮局"。
对比项交换机路由器
工作层次二层（数据链路层）三层（网络层）
转发依据MAC 地址表路由表
能否跨网段不能能
隔离广播域不能能
典型用途接入终端、汇聚连接网段、上联出口

三层交换机也能配 IP 路由，但它侧重"局域网内线速转发"；路由器侧重"异构网络互联、路由协议学习、WAN 链路封装"，还支持 NAT、VPN、QoS 等广域网特性。

1.2 路由表的作用

路由表是路由器转发报文的"GPS"，每台路由器依据它决定报文从哪个接口发给谁。查看命令：

<R1>display ip routing-table
Route Flags: R - relay, D - download to fib
------------------------------------------------------------------------------
Routing Tables: Public
         Destinations : 5        Routes : 5
Destination/Mask    Proto   Pre  Cost      Flags NextHop         Interface
     10.0.0.0/8      Direct  0    0           D   10.0.0.1        GigabitEthernet0/0/0
     10.0.0.1/32     Direct  0    0           D   127.0.0.1       GigabitEthernet0/0/0
    192.168.1.0/24   Static  60   0           D   10.0.0.2        GigabitEthernet0/0/0
    192.168.2.0/24   OSPF    10   2           D   10.0.0.3        GigabitEthernet0/0/1
    0.0.0.0/0        Static  60   0           D   10.0.0.254      GigabitEthernet0/0/2

**关键字段解释**：

- **Dest/Mask**：目的网段。
- **Proto**：路由来源（Direct 直连 / Static 静态 / OSPF / RIP / BGP 等）。
- **Pre**：优先级，数值**越小越优**，路由器选择路由时先比优先级。
- **Cost**：开销，优先级相同时再比 Cost，越小越优。
- **NextHop**：下一跳 IP（下一台设备接口地址）。
- **Interface**：出接口。

### 1.3 路由器硬件组成

- **接口（Interface）**：
  - 物理接口：GE/FE（以太网口，`GigabitEthernet` / `FastEthernet`）、Serial（串口，连接广域网如 PPP/HDLC）、E1 接口（连接传输网）。
  - 逻辑接口 逻辑接口：LoopBack（环回口）、Tunnel（隧道口）、Vlanif 等，由软件创建。
- **存储**：Flash（存放系统软件/配置文件，掉电不丢）、RAM（运行内存）、NVRAM（启动配置文件备份）、BootROM（引导程序）。
- **模块**：光模块（SFP）、WAN 接口卡、语音模块等，即插即用扩展。

2. 登录与管理

2.1 Console 线登录

  • 用 Console 线连接路由器 Console 口与电脑串口（笔记本需 USB 转串口线）。
  • 打开终端软件（SecureCRT / Xshell / Putty / MobaXterm），选择对应串口（如 COM3）。
  • 参数固定为：波特率 9600、数据位 8、停止位 1、无校验、无流控。
  • 上电后默认进入用户视图 <Router>（V8 出厂默认有默认 Console 密码 admin，通过 Console 可以进入用户视图用 system-view 进入系统视图）。

2.2 Telnet / SSH 登录配置

设备需要先配置管理 IP 才能远程登录（局域网内通常配置 LoopBack 或 Vlanif 地址）。

① 开启 Telnet（华三需额外执行 telnet server enable）

<Router>system-view
[Router]interface GigabitEthernet0/0/0
[Router-GigabitEthernet0/0/0]ip address 192.168.10.1 255.255.255.0
[Router-GigabitEthernet0/0/0]quit
[Router]telnet server enable                  # 华为默认开启；华三需手动开启
[Router]user-interface vty 0 4               # 0~4 共5个虚拟终端
[Router-ui-vty0-4]authentication-mode password
[Router-ui-vty0-4]set authentication password cipher Huawei@123
[Router-ui-vty0-4]user privilege level 15    # 登录后最高权限（H3C 华三为 user privilege level 3）
[Router-ui-vty0-4]quit

② 开启 SSH（更安全，生产环境推荐）

[Router]rsa local-key-pair create            # 生成 RSA 密钥（华三：public-key local create rsa）
The key name will be: Host
% RSA keysize[2048]:直接回车
[Router]ssh user admin                         # 创建 SSH 用户 admin
[Router]ssh user admin authentication-type password
[Router]ssh user admin service-type stelnet    # 允许 SSH 登录
[Router]user-interface vty 0 4
[Router-ui-vty0-4]protocol inbound ssh         # 仅允许 SSH 进入（禁 Telnet）
[Router-ui-vty0-4]authentication-mode aaa
[Router-ui-vty0-4]quit
[Router]aaa
[Router-aaa]local-user admin password cipher H3C@2024
[Router-aaa]local-user admin service-type ssh
[Router-aaa]local-user admin privilege level 15

从 PC 登录：ssh admin@192.168.10.1（Windows 10+ 自带 OpenSSH；SecureCRT 亦可）。Telnet 明文传输，只用于内网实验环境。

2.4 配置文件管理

华为 VRP 配置分"当前配置"和"保存配置"两级，重启后只保留已保存的配置：

<Router>save                       # 保存配置到 Flash（输入 y 确认，可指定文件名）
<Router>display saved-configuration    # 查看已保存的启动配置
<Router>reset saved-configuration      # 删除保存配置（慎用）
<Router>reboot                    # 重启设备（先 save 再 reboot 才生效）
<Router>display startup             # 查看下次启动加载的配置文件

3. 接口基础配置

3.1 物理接口启用

华为 VRP 接口默认是 Up 的（协议 up），但很多场景下接口因被 shutdown 而 down，需启用：

[Router]interface GigabitEthernet0/0/0
[Router-GigabitEthernet0/0/0]undo shutdown

华三 Comware 接口编号为 GigabitEthernet1/0/1 这种"槽位/子槽/端口"三段式，默认也是启用。

3.2 接口 IP 配置

[Router]interface GigabitEthernet0/0/0
[Router-GigabitEthernet0/0/0]ip address 192.168.10.1 255.255.255.0
  • 配置后立即生效，该接口便产生一条直连路由。
  • 华为命令 ip address 192.168.10.1 24（支持前缀长度）；华三必须写全掩码或使用 ip address 192.168.10.1 24（H3C 新版也支持 24 简写）。
  • 验证：display ip interface brief

3.3 环回口 Loopback 与子接口

① 环回口（永远 Up 的逻辑口，用于设备标识、OSPF/BGP 的 Router-ID、网管地址）：

[Router]interface LoopBack0
[Router-LoopBack0]ip address 1.1.1.1 255.255.255.255

② 子接口（单臂路由，将一个物理口划成多个逻辑口）：

[Router]interface GigabitEthernet0/0/2.10
[Router-GigabitEthernet0/0/2.10]dot1q termination vid 10     # 打上802.1Q标签，VLAN10
[Router-GigabitEthernet0/0/2.10]ip address 192.168.10.254 255.255.255.0
[Router-GigabitEthernet0/0/2.10]quit

4. 直连路由与静态路由

4.1 路由表构成回顾

路由优先级 Pre 默认值（华为）：

路由来源Pre路由来源Pre
Direct（直连）0RIP10（华为）
OSPF5（内部）/15（外部）静态 Static60
BGP255IBGP255

华三 Pre：Direct 0、Static 60、RIP 100、OSPF 10、BGP 255（外部 EBGP 255、IBGP 255）。

4.2 静态路由配置

[Router]ip route-static 192.168.20.0 255.255.255.0 192.168.10.2

含义：去往 192.168.20.0/24 的报文，交给下一跳 192.168.10.2。 （华三写法相同：ip route-static 192.168.20.0 24 192.168.10.2）

可配出接口（多用于点对点链路）：

[Router]ip route-static 192.168.30.0 255.255.255.0 Serial1/0/0

建议指定下一跳（更准确、不影响 ARP 解析）。

删除静态路由：undo ip route-static 192.168.20.0 255.255.255.0

验证静态路由连通性：ping -a 源地址 目标IP（华为支持 ping -a 指定源地址）

4.3 默认路由

当路由表无匹配条目时，路由器使用默认路由（又称"缺省路由"），常用于出口上联运营商：

[Router]ip route-static 0.0.0.0 0.0.0.0 10.0.0.254
# 华三: ip route-static 0.0.0.0 0 10.0.0.254

4.4 黑洞路由

把丢弃的流量"吸"进黑洞，用于防环路或过滤攻击流量：

[Router]ip route-static 192.168.100.0 255.255.255.0 NULL0

静态路由+NULL0 典型用法：汇总网段中不存在实际接口时，防止路由黑洞环路。

4.5 路由选路原则（重要考点）

路由器收到多条到达同一目的网段的路由时，按以下顺序优选：

  1. 先比优先级（华为 Preference / 华三协议优先级）：数值小者优先。华为：Direct(0) > OSPF(10) > Static(60) > RIP(100) > BGP(255)。
  2. 优先级相同，再比度量值 Cost：数值小者优先。静态路由 Cost 默认 0；OSPF 的 Cost 与带宽成反比（10^8/带宽）。
  3. 优先级与 Cost 均相同，则多路径负载分担（华为默认支持 ECMP 等价路由）。

例：静态路由与 OSPF 同时有去往 10.1.0.0/16 的路由，只要不调优先级，路由器会优先选 OSPF（Pre 10 < 60，数值小者优先）。若想固定走某条静态链路，可把该静态路由的 Pre 调小（如调成 5）或干脆删掉 OSPF 路由；若想让静态路由做"最后保底"，则把它的 Pre 调大即可，详见中级篇"浮动静态路由"。

4.6 静态路由管理距离调整

[Router]ip route-static 10.1.0.0 255.255.0.0 192.168.1.1 preference 70

把该条静态路由优先级从 60 改为 70（比 OSPF 的 10 大），这样 OSPF 路由优先生效，该静态路由只在 OSPF 不可用时作为备份接管。

华三：ip route-static 10.1.0.0 16 192.168.1.1 preference 70（命令一致）。

5. 三层通信原理

5.1 ARP 的作用

  • ARP（地址解析协议）：把"已知 IP"解析成"数据链路层所需的 MAC 地址"。
  • 同一网段 A 访问 B：先查 ARP 表，无则广播 ARP 请求"谁是 192.168.10.2"，B 单播应答，A 记录到 ARP 缓存（默认老化时间 120 分钟华为）。
<Router>display arp             # 查看 ARP 表
<Router>reset arp all           # 清空 ARP（排障用）

5.2 跨网段通信流程

假设 PC-A（192.168.10.10/24，网关 192.168.10.1）访问 PC-B（192.168.20.20/24，网关 192.168.20.1），经路由器 R 转发：

  1. PC-A 发现目的 IP 与自己不在同网段，把报文交给网关 MAC（路由器的 MAC）——通过 ARP 查询网关 192.168.10.1 的 MAC。
  2. 报文到达路由器 GE0/0/0 接口，路由器解封二层看 IP 目的 192.168.20.20，查路由表。
  3. 路由表有 192.168.20.0/24 的直连路由 → 决定从 GE0/0/1 出。
  4. 路由器在 GE0/0/1 网段上 ARP 查询 192.168.20.20 的 MAC，重新封装帧头（源 MAC 变成出接口 MAC），发给 PC-B。
  5. PC-B 回复，逆流程返回，源/目的 IP 全程不变，MAC 逐段变化。

一句话记法：路由决定"去哪"，ARP 决定"找谁"，MAC 只在本网段有效。

5.3 动手实验：eNSP 验证跨网段通信

拓扑：PC1(192.168.10.10/24, GW 192.168.10.1) --- GE0/0/0 R1 GE0/0/1 --- PC2(192.168.20.20/24, GW 192.168.20.1)

R1 配置：

<Huawei>system-view
[Huawei]sysname R1
[R1]interface GigabitEthernet0/0/0
[R1-GigabitEthernet0/0/0]ip address 192.168.10.1 255.255.255.0
[R1-GigabitEthernet0/0/0]quit
[R1]interface GigabitEthernet0/0/1
[R1-GigabitEthernet0/0/1]ip address 192.168.20.1 255.255.255.0
[R1-GigabitEthernet0/0/1]quit

验证步骤：

[R1]display ip interface brief        # 两个接口均 up，IP 正确
[R1]display ip routing-table          # 出现两条 Direct 路由 192.168.10.0/24、192.168.20.0/24
[R1]ping 192.168.20.20                # 源 192.168.10.1 ping PC2，应通

在 PC-A 上执行 ping 192.168.20.20，能通即说明三层路由转发成功。若不通，按顺序检查：接口状态 → 双方 IP/掩码 → 网关配置 → 路由表 → ARP 表。

6. 链路层封装：PPP 协议

6.1 HDLC 与 PPP 对比

  • HDLC（高级数据链路控制）：点对点默认链路封装，华为/华三采用标准 HDLC 帧格式（Cisco 的 HDLC 是私有扩展），无认证能力。
  • PPP（点对点协议）：标准协议，支持多协议封装、认证（PAP/CHAP）、链路质量检测、多链路捆绑，广域网（专线/拨号）主流。
特性HDLCPPP
标准性思科私有国际标准 RFC 1661
认证无PAP / CHAP
多协议承载支持（私有）支持
适用同厂商跨厂商、拨号、专线

查看/修改接口封装：

[Router]interface Serial1/0/0
[Router-Serial1/0/0]link-protocol ppp      # 设为PPP（华为默认就是PPP）

华三默认链路协议为 PPP，命令相同。

6.2 PPP 认证配置（PAP / CHAP）

例：R1 与 R2 串口互联，R2 做验证方（Authenticator），R1 是被验证方（Supplicant）。

① R2 配置（对端认证 + 本地用户库）：

[RouterB]aaa
[RouterB-aaa]local-user R1 password cipher Huawei@2024
[RouterB-aaa]local-user R1 service-type ppp
[RouterB-aaa]quit
[RouterB]interface Serial1/0/0
[RouterB-Serial1/0/0]ppp authentication-mode chap     # 也可以换成 pap
[RouterB-Serial1/0/0]ip address 10.0.0.2 255.255.255.0

② R1 配置（填写用户名/密码）：

[RouterA]interface Serial1/0/0
[RouterA-Serial1/0/0]ppp chap user admin
[RouterA-Serial1/0/0]ppp chap password cipher R@2024
[RouterA-Serial1/0/0]ip address 10.0.0.1 255.255.255.0

PAP 与 CHAP 区别：PAP 密码以明文两次握手传输（仅认证一次）；CHAP 通过挑战-应答三次握手，密码不直接上线路，更安全。

  • PAP：ppp authentication-mode pap + R1 配 ppp pap local-user admin password cipher R@2024
  • CHAP 默认以用户名认证，用户名不区分大小写；华三通过 ppp authentication-mode pap 类同。

验证：

[RouterA]display ppp interface Serial1/0/0
display interface Serial1/0/0          # 链路状态 Up、Up

6.3 PPP 链路建立过程（三个阶段）

PPP 建链走"三步走"，与认证结合的完整流程：

  1. LCP（链路控制协议）协商：双方协商 MRU、认证方式等，协商成功链路进入 Up。
  2. 认证阶段（可选）：若配置了 PAP/CHAP，则在此阶段验证对端身份；认证失败直接拆链。
  3. NCP（网络控制协议）协商：为上层网络层协议分配参数，如 IPCP 协商接口 IP 地址（可配 IP 地址协商，常用于拨号场景，服务端自动分配 IP）。

排障看链路状态：display interface Serial1/0/0 中 Line protocol 为 Up 才代表 PPP 协商成功；若 Physical Layer 是 up、Link Layer 是 down，通常说明 LCP 未协商成功（如对端封装不是 PPP、认证失败）。

查看 PPP 报错与调试：

<RouterA>debugging ppp all          # 打开 PPP 调试（排障后记得 undo debugging all）
<RouterA>terminal debugging         # 终端同步显示调试信息
