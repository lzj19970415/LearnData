01 应急响应入门（服务器被入侵了怎么办）

学这个之前先记住一句话：发现被入侵，第一反应不是"赶紧杀进程"，而是"先保护现场"。

一、先说人话：什么是应急响应

把服务器想成你自己家的房间。

  • 你回家发现门锁被撬了、东西被翻动过——这就是"被入侵了"。
  • 这时你不会先去把门关上就开始擦指纹，对不对？你要先：确认丢了什么、小偷是从哪进来的、现在有没有还躲在你家里，然后才考虑怎么把门修好、加几道锁。
  • 应急响应就是这件事：先搞清楚"发生了什么、还在不在"，再处理、再堵漏。

所以核心顺序是死的，别搞反：

第一步：隔离（先别让攻击者继续动手 / 别把现场弄乱）
第二步：查"谁还在里面"（进程、外联）
第三步：查"攻击者留下了什么后门"（持久化）
第四步：查"多了哪些账户"
第五步：查"他干了什么"（日志）
最后：清理 + 加固 + 复测

⚠️ 重点：先隔离，别关机！ 关机等于把"他干过什么"的证据（内存里）都删了。应急响应里断电断网是最后的手段。

二、第一步：隔离——人话

  • 目的：切断攻击者的控制，同时保住证据。
  • 动作：断外网（拔网线 / 在安全组上封掉对外），但别关机。如果是被挖矿木马外联，先封它的外联方向。

三、第二步：看"还有谁在里面"——进程和网络

Windows 上怎么查（人话+命令）

netstat -ano        # 看这台机器连了谁 —— 有 ESTABLISHED(已建立) 连陌生 IP 的，记下它的 PID
tasklist /v         # 按 PID 找是哪个进程在连

怎么看：重点找"进程名像系统、但路径不对"或"连到不认识的 IP"的进程。

Linux 上怎么查

ps -ef                    # 所有进程
ls -l /proc/<PID>/exe      # 这个进程真正的路径（最准，命令伪装骗不了这招）
netstat -antup            # 看外连

人话：一个进程"说"自己是系统的，你要看它真身路径是不是系统目录，不看它叫什么名字。木马最爱伪装成 svchost / java 这类常见进程。

四、第三步：看"留下了什么后门"——持久化

什么是持久化（人话）

攻击者想让服务器"重启之后后门还在"。他会把后门挂到"开机自动启动"的地方。你只要查这些地方就行。

Windows 查五个地方（记一下，是高频考点也是实操点）：

# ① 注册表开机启动
reg query "HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Run"
# ② 计划任务
schtasks /query /fo LIST /v
# ③ 服务（有没有装了个可疑服务）
services.msc

Linux 查五个地方（对应记）：

crontab -l                        # 计划任务
systemctl list-units --type=service --state=running   # 正在跑的服务
cat /etc/rc.local                # 开机脚本
cat ~/.ssh/authorized_keys        # SSH 后门（陌生公钥=能直接免密进来）
awk -F: '$3==0 {print $1}' /etc/passwd   # 看看有没有"普通账户但权限是root"的怪东西

人话：凡是"开机自动启动 / 定时自动跑"的地方，都可能藏后门，挨个看一遍。

五、第四步：查账户——谁多了个管理员

# Linux：看有没有非 root 但 UID=0 的账户
awk -F: '$3==0 {print $1}' /etc/passwd
# Windows
net user
net localgroup administrators

人话：攻击者常会给自己"加一个管理员账户"，以后偷偷进来。看到不认识的账户、尤其是有管理员权限的，就有问题。

六、第五步：查日志——还原"他干了什么"

日志是"案发现场的录像"。Windows 看事件查看器，Linux 看 /var/log。

重点看这几个事件（记这 6 个就够入门）：

事件 ID含义什么时候该注意
4624登录成功大量出现 = 有人爆破/异地登录
4625登录失败大量 = 在试密码（暴力破解）
4720创建了账户陌生账户，就是后门
7045装了新服务后门安装动作
4698建了计划任务可能埋定时后门
1102日志被清空最可疑，攻击者抹痕迹

Linux：/var/log/secure（SSH 登录记录）、~/.bash_history（敲过的命令）。看到 Failed password ... from x.x.x.x 反复出现 = 在爆破。

七、最后一步：清理 + 加固 + 复测

删除后门/可疑账户/计划任务 → 打补丁改口令 → 用同样的攻击再试一次确认堵死了 → 留记录

人话：不是删完就完，要"用你的方法打一次确认打不进来"，这才叫堵漏了。

小结（人话速记）

  1. 先隔离不断电，保留证据。
  2. 顺序：进程 → 持久化 → 账户 → 日志。
  3. Windows 后门看：注册表 Run / 计划任务 / 服务 / 启动项。
  4. Linux 后门看：cron / systemd / rc.local / 公钥 / UID=0 账户。
  5. 最可疑的日志事件：1102（日志被清空）、4720（建号）。
  6. 最后必须复测才叫加固完。

想去动手：找一台测试机（虚拟机即可），上面放一个"模拟被入侵"的环境，按这五步走一遍，你就真会了。
