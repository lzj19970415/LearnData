04 数据安全基础（分类分级/风险评估/合规）

对应 10月21日上午：数据分类分级方法（国标/行标与电信行业实践）、风险评估流程、治理与合规要点。

一、法律法规基础【背】

法律/法规施行时间一句话定位
《网络安全法》2017.6.1基础法，定等级保护、实名制
《数据安全法》2021.9.1数据安全基础法，分类分级、重要数据
《个人信息保护法》2021.11.1敏感个人信息、"单独同意"
《关键信息基础设施安全保护条例》2021.9.1关基认定与保护

数安法核心考点【背】：

  1. 数据分类分级保护制度是数据安全法确立的核心制度（第 21 条）。
  2. 数据分级：一般数据、重要数据、核心数据三级，核心数据实行更严格管理。
  3. 重要数据目录由各地区、各部门制定。
  4. 违反向境外提供重要数据：最高 1000 万罚款（情节严重可吊证）。

二、数据分类分级方法【背】

1. 国标依据

  • GB/T 43697-2024《数据安全技术 数据分类分级规则》：分类分级总国标，2024.10.1 实施。
  • 分类 = 按业务属性划分（先分行业领域，再分业务条线）。
  • 分级 = 按影响后果定级。

2. 分级四级口诀（国标）【背】

一般数据 → 低、较高风险为"一般"
重要数据 → 危害国家安全/公共利益为"重要"
核心数据 → 严重危害为"核心"
（分级考虑：保密性、完整性、可用性 三性影响）

国标 43697 把危害后果从低到高分为：无危害 → 轻微 → 一般 → 严重 → 特别严重，对应一般/重要/核心。

3. 分类方法五步【背】

数据资产梳理 → 业务属性分类 → 影响后果识别 → 分级判定 → 打标签入台账

4. 电信行业实践【懂】

  • 电信领域数据分类：按业务条线分（用户数据、业务数据、经营管理数据、网络运维数据等）。
  • 用户个人信息中身份证号、手机号、位置、通信内容属高敏感，脱敏/加密是标配。
  • 出境评估：重要数据出境需安全评估（网信办），个人信息达到规模需评估或认证。

三、风险评估流程【背】

① 资产识别 → ② 威胁识别 → ③ 脆弱性识别 → ④ 已有安全措施确认 → ⑤ 风险分析与研判 → ⑥ 结论与整改建议
  • 资产 = 数据资产（数据集、接口、台账）
  • 威胁 = 谁可能危害它（外部攻击、内部违规、供应链）
  • 脆弱性 = 管理漏洞+技术漏洞（无制度、权限过大、无日志）
  • 研判公式记忆：风险 = 脆弱性 × 威胁 × 资产价值（可能性×影响）

四、治理与合规要点【背】

1. 治理框架记忆

  • 组织：数据安全负责人、管理机构（重要数据处理者必设）
  • 制度：分类分级制度、全流程管控制度、应急演练（每年至少一次）
  • 风险评估：重要数据定期开展风险评估并报送（数安法第 30 条）
  • 培训：全员数据安全培训教育

2. 处罚速记【背】

  • 一般违规：责令改正+警告，拒不改正 5-50 万，直接责任人 1-10 万
  • 重要数据违规：50-200 万（可停业/吊证/直接负责人罚款）
  • 向境外提供重要数据：100-1000 万
  • 阻碍国家机关监管：10-100 万

五、高频考点提示

  1. 两个日期必背：数安法 2021.9.1、个保法 2021.11.1。
  2. 三级：一般/重要/核心；四级判据：保密性/完整性/可用性影响。
  3. 评估五步顺序不能乱：资产→威胁→脆弱性→措施→研判。
  4. 每年应急演练至少一次、重要数据定期评估并报送。
  5. 答题模板："依据 XX 法第 X 条 + 本单位做法 + 改进建议"，三段式。
