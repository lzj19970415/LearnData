软件管理

Linux（红帽系）安装软件有四种途径：yum、rpm、source（源码编译）、bin（二进制）。日常以 yum 为主、rpm 为辅，特殊需求用源码编译。本篇重点掌握 RPM 包结构与 rpm/yum 两套工具。

Linux 软件包管理机制

红帽系软件管理分类

方式 说明 典型场景
yum 基于 RPM 的包管理器，自动解决依赖，需配置软件仓库 日常安装首选
rpm 直接安装 RPM 包，不解决依赖 离线安装单个包、查询包信息
source 源码编译安装（configure → make → make install） 需要新版本/自定义模块
bin 官方提供的二进制安装包/脚本（如 .run、.bin） JDK 等官方安装器

一、路由基础

1. 路由的三种来源

路由器转发数据时，需要在路由表中查找相应路由。路由表中的路由有三种途径：

  1. 直连路由：路由器自动添加和自己直连的网段路由；
  2. 静态路由：管理员手动添加的路由；
  3. 动态路由：由路由协议（如 OSPF、RIP、BGP）动态建立的路由。

文件服务器（Samba/FTP/NFS 等）

Linux 下常用的文件共享服务有三类：FTP（跨平台文件传输）、NFS（Linux 之间的文件级共享，性能最好）、Samba（Linux 与 Windows 之间的共享）。本篇以 Vsftpd 为主线，兼顾 NFS 与 Samba，最后补充 NAS/SAN 存储概念。

FTP 文件传输协议

FTP 基本概念

  • FTP（File Transfer Protocol）基于 TCP 协议，实现文件的上传、下载、删除与共享。
  • 采用 C/S（客户端/服务器） 模式：服务端提供共享，客户端上传下载；一个服务端可同时服务多人。
  • FTP 会建立两条 TCP 连接：
    • 控制连接：传输命令信息（固定 21 端口）；
    • 数据连接：实际传输文件数据。
  • 主流 FTP 服务端软件：Vsftpd（Linux 最主流）、ProFTPD、PureFTPd、Server-U、FileZilla Server 等。

Web 服务基础

什么是 Web 服务器

  • 最主流的三大 Web 服务器：Apache、Nginx、IIS。
  • Web 服务器是驻留在服务器上的被动程序：只有浏览器发起请求时才响应。
  • 服务器通过 HTTP（超文本传输协议） 与浏览器交流，因此也叫 HTTP 服务器。
  • 能存储信息、放置网站文件供浏览/下载，也能在用户请求基础上运行脚本和程序（动态内容）。
